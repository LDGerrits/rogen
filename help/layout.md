# Layout

- A `(Name)/` folder groups files on disk and is left out of the tree. `(Server)/` is still a routing folder.
- A directory with an `init` script (`init.luau`, `init.server.luau`, roblox-ts's `index.ts`) is one instance: the script is the folder, and the other files in it are its children, each routed like any other file. An `init.csv` makes the folder a LocalizationTable the same way.
- A script beside a folder of its name (`Dup.luau` and `Dup/`) is one script, and the files in the folder are its children, as an init script and its folder are. Rojo itself would build them as two siblings of the same name.
- An init script's route (`init@server.luau`, or `init.server.luau` with a `server` key) routes its whole folder like a marker file, and routing folders inside it are ordinary folders.
- A folder split across routes becomes an instance in each, and each gets a copy of its init ModuleScript with only the files routed there (`rogen where` adds `· also <path>` for each copy); an init Script is never copied. A copy's children depend on where it sits, not who runs it, and the server may load two copies, so keep a copied init stateless and use `script:FindFirstChild` rather than `RunService` to pick children.
- An init script with no folder of its own to become, in a source path or a plain routing folder, is an error.
- A file's `.meta.json` is named after the name Rojo gives it, which drops `.server`, `.client` and `.plugin` and keeps `@` and `^`: `Save.server.luau` takes `Save.meta.json`, `TradeService@Server.luau` takes `TradeService@Server.meta.json`, and `^Animate.client.luau` takes `^Animate.meta.json`. A meta no file claims warns.
- A feature folder's `init.meta.json` (`{ "className": "Actor" }`) applies to every node the folder becomes. `className` in a folder with an init script is an error, since the script decides the class. In a governing routing folder or an invisible folder it applies to nothing, and Rogen warns. A `Name@key` folder and a routing folder an outer route outranks are ordinary folders.
- A folder holding a `default.project.json` is that project, as in Rojo: one instance named by the project's `name`, with only what its `tree` mounts. Rogen doesn't route the other files in it (`rogen where`: `in a nested project`). Another `X.project.json` is one instance named by its `name`. A `default.project.json` directly in a source path is placed on its own and warns.
- Data files and models route like scripts, with the route before the extension (`Prices@shared.json`): `.json`, `.jsonc`, `.toml` and `.yaml` are ModuleScripts, `.txt` a StringValue, `.csv` a LocalizationTable, `.rbxm`, `.rbxmx` and `.model.json` their model. A folder with nothing that becomes an instance (empty, or only a `.gitkeep` or `README.md`) is an empty Folder, as in Rojo.
- `globIgnorePaths` globs are neither routed nor warned about; an ignored folder isn't read, and `rogen where` names the glob that matches. A `.rogen.json` in a source path is never synced.
- A symlink or junction inside a source path is read as the directory it points at, and keeps its own path in the output. A link that points at nothing, or back at a directory that holds it, is skipped with a warning.
