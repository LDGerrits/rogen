# Configs

A folder's config is `rogen.json` (or `rogen.jsonc`), parsed as JSONC. It is a Rojo project file plus Rogen's keys: `sourcePaths` (default `["src"]` when `routes` exist), `routes`, `syncPath`, `projects`, `serveProject` and `placePaths`. Rojo's keys (`name`, `tree`, `servePort`, `servePlaceIds`, `emitLegacyScripts`, `globIgnorePaths` and the rest) pass through to the project file Rogen writes beside it, `default.project.json`. A key on neither list passes through with a warning, since Rojo will reject the written file by that name. A command given no folder reads the `rogen.json` here, or in the nearest folder above that has one.

- `tree` is the instance tree Rogen merges its generated nodes into, as in any Rojo project file. It holds what names can't express: the DataModel name, package mounts and `$properties`. The tree wins a clash. A `$path` into a source path is Rojo's: Rogen skips that folder, so mount vendored code there to sync it as it is. With `routes`, the tree's root must be a DataModel; without them any root is valid and the file is written as it is.
- Without `routes`, nothing is routed and no source path is scanned, and `sourcePaths` is an error. Rogen warns when `src` holds files the tree doesn't mount.
- Several `sourcePaths` merge into one tree, and the later one wins a clash. Paths are relative to the folder of `rogen.json`.
- `globIgnorePaths` lists globs, relative to the folder, that Rojo ignores and Rogen keeps out of routing, such as `**/*.spec.luau`. It never drops a mounted node: an ignored mount stays as an empty Folder.
- `syncPath` is the compiler's output (`out` for roblox-ts, `dist` for Darklua), where emitted `$path`s point.
- `projects` writes more project files from the same description: each key is a name, written as `<name>.project.json` beside `default.project.json`, and each value is the keys that differ. A value replaces the inherited one, a list replaces the list, `routes`, `tree` and the nodes below it merge by key, and `null` removes a key (`"DevPackages": null` drops a mount); `null` in the description itself is an error. A project may change any key but `projects` and `serveProject`, inherits `name`, and always carries a `name` in its file, since Rojo can't open a project file without one. `default` is the description and can't be a project name.
- `serveProject` names the project `rogen serve` serves (default `default`). Every other command reads `default`. A command's `[PROJECT]` may be a project's name (`rogen serve release`) or its file (`dist.project.json`), unless a folder of that name holds a `rogen.json` or a `default.project.json`: the folder wins. `rogen build` writes every project; `rogen list` shows each one's file and which is served.
- `placePaths` lists folder globs (`places/*`) that make each matching folder a place. A place inherits this config, adds its own `sourcePaths` after the inherited ones (never replacing them), gets its own project files in its folder, and is named after its folder unless it sets `name`. A place needs no `rogen.json`; one holds what differs, and `null` in it removes a key it inherits (`"servePlaceIds": null`). Give each place its own `servePlaceIds`, so a Studio on another place refuses to connect to its port. Inherited relative paths (`$path`s, `globIgnorePaths`, `syncPath`) are written relative to each place. The config that lists places writes its own files and is never served; `rogen serve` serves the places, a place without `servePort` on 34872 plus its index among the unpinned places sorted by path, and a port in use is an error naming `servePort`.
- `syncRules` is Rojo's list of rules that turn a file name into an instance, tried before Rojo's own. Rogen reads files by it and writes it to each project file, moved with the files it takes. `extends`, `template`, `outFile` and `exclude` are errors that name what replaces them.

The project file carries `name` only when `rogen.json` sets one; Rojo names the project after its folder otherwise.

Ownership:

- `rogen build` overwrites `default.project.json`: put changes in `rogen.json`.
- The `syncPath` is compiler output: edit the sources in the source paths.
