## Rogen

Rogen writes each Rojo project file from the folders and file names under its config's `rogen.sourcePaths` (`X.rogen.json` writes `X.project.json`). Folders decide where code runs, so the disk path is not the instance path.

- Edit the code and the `.rogen.json`; each write replaces the `*.project.json`. Each `.rogen.json` is complete and reads no other, so make a change to `routes`, `sourcePaths` or `tree` in every config it applies to (`dist`, other places). Edit it in place to keep its comments.
- The route keys are the names in `rogen.routes` (`Server`, `Client`, `Shared`). A folder named after a key, or an `@key` suffix (`Save@server.luau`), routes what it holds. The first route below the source path governs, so `Shared/Server/` ships to clients: keep server-only code under a server route.
- Put a new file beside files like it. `rogen where <path>` prints where it lands, before or after it exists, and the Luau `require` that reaches it. roblox-ts imports by relative path.
- After changing files or a `.rogen.json`, run `rogen check <paths>` from the repo root and fix what it prints. A file no config holds (roblox-ts `projects/common`) is skipped: check it through a place, `rogen check projects/game`.
- Every other command reads only the current folder: run it where the `.rogen.json` is, or name the config (`rogen write lobby`, `rogen serve projects/lobby`).
- Run `rogen write` after adding files and before `rbxtsc`. `rogen serve` and `rogen write --watch` rewrite on their own; `--watch` never exits, so leave it to the user. `rogen build -o <file>` builds a place or model file.
- To sync to Studio, start `rogen serve --json` in the background. It exits 0 at once when another serve has the project. Otherwise it prints `serving` once Studio can connect; on write errors it waits for your fix, so keep it running. When `serving` has `"reportsConnections": true`, Studio has your edits after `connected`; if that never comes, ask the user to press Connect in Rojo's Studio plugin.
- Read `rogen doc routing` before adding a route or a new kind of folder, or when `where` surprises you. `rogen help <command> --json` lists flags and the `--json` shape; `rogen help <code>` explains a diagnostic.
