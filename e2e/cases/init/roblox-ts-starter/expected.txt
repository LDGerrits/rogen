# project
Generated by [Rogen](https://rogen-playfully.vercel.app/).

## What's here
`src/Greeter` is a feature: one folder for the code that belongs together.

`place` holds Rojo's sample Baseplate and the Lighting and SoundService settings, as Rojo files: an `init.meta.json` per service and `Workspace/Baseplate.model.json`. The tree in `default.rogen.json` mounts each service's folder, and Rogen routes nothing in it.

The folders inside it decide where its code runs: `server` goes to ServerScriptService, `client` to StarterPlayerScripts and `shared` to ReplicatedStorage. To see where a file lands, and how to require it, use:

```bash
rogen where src/Greeter/shared/Greeting.ts
```

## Getting Started
To compile the TypeScript, and keep compiling it as you edit, use this in a terminal of its own:

```bash
npm run watch
```

To build the place from scratch, use:

```bash
rogen build -o "project.rbxlx"
```

Next, open `project.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rogen serve
```

For more help, check out [the Rogen documentation](https://rogen-playfully.vercel.app/).
