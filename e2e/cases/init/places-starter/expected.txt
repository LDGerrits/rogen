README.md:
# project
Generated by [Rogen](https://rogen-playfully.vercel.app/).

## What's here
`places/shared/src` holds the code every place shares, here the `Greeter` feature: one folder for the code that belongs together. `places/game` holds the code of the game place alone.

The folders inside a feature decide where its code runs: `Server` goes to ServerScriptService, `Client` to StarterPlayerScripts and `Shared` to ReplicatedStorage. To see where a file lands, and how to require it, use:

```bash
rogen where places/shared/src/Greeter/Shared/Greeting.luau
```

Open `project.code-workspace` rather than the folder, so the editor runs a language server for each place.

## Getting Started
To serve every place, each on its own port, and connect to one from Roblox Studio, use:

```bash
rogen serve
```

To build the game place from scratch, use:

```bash
rogen build places/game -o "project.rbxlx"
```

To add a place, use:

```bash
rogen init places/lobby
```

For more help, check out [the Rogen documentation](https://rogen-playfully.vercel.app/).
