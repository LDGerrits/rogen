README.md:
# project
Generated by [Rogen](https://rogen-roblox.vercel.app/).

## What's here
`src/common` holds the code every place shares, here the `Greeter` feature: one folder for the code that belongs together. `src/game` holds the code of the game place alone.

A place is a `<place>.rogen.json` at the root: `game.rogen.json` lists the source paths `src/common` and `src/game`, and Rogen writes `game.project.json` from it.

`place/game` holds Rojo's sample Baseplate and the Lighting and SoundService settings, as Rojo files: an `init.meta.json` per service and `Workspace/Baseplate.model.json`. The tree in `game.rogen.json` mounts each service's folder, and Rogen routes nothing in it.

The folders inside a feature decide where its code runs: `Server` goes to ServerScriptService, `Client` to StarterPlayerScripts and `Shared` to ReplicatedStorage. To see where a file lands, and how to require it, use:

```bash
rogen where src/common/Greeter/Shared/Greeting.luau
```

`rogen check` and `rogen where` find the place a path belongs to, and a file in `src/common` belongs to every place. `rogen check` with no path checks every place. `rogen where` finds no `default.rogen.json` here, so name the place: `rogen where game.rogen.json`.

## Getting Started
To serve the game place and connect to it from Roblox Studio, use:

```bash
rogen serve game
```

To build the game place from scratch, use:

```bash
rogen build game -o "project.rbxlx"
```

## Adding a place
Copy `game.rogen.json` to `lobby.rogen.json`, change its `name` to `lobby` and its source path `src/game` to `src/lobby`, and make the `src/lobby` folder. A second place is served from a second terminal, with its own `--port`:

```bash
rogen serve lobby --port <port>
```

## Editor
A sourcemap describes one place, so luau-lsp knows one place at a time: the one in `.vscode/settings.json`. It runs

```bash
rogen sourcemap game --watch -o sourcemap.json
```

to keep `sourcemap.json` current as files come and go. To switch place, change `game` to the name of another in that setting.

To check every place exactly at once, for an agent or CI, check each place against its own sourcemap:

```bash
rogen sourcemap game -o sourcemap.json && luau-lsp analyze --definitions=@roblox=<types.d.luau> --sourcemap=sourcemap.json src/common src/game
```

For more help, check out [the Rogen documentation](https://rogen-roblox.vercel.app/).
