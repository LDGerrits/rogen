# project
Generated by [Rogen](https://rogen-roblox.vercel.app/).

## What's here
`src/greeter` is a feature: one folder for the code that belongs together.

The folders inside it decide where its code runs: `server` goes to ServerScriptService, `client` to StarterPlayerScripts and `shared` to ReplicatedStorage/Shared. To see where a file lands, and how to require it, use:

```bash
rogen where src/greeter/shared/greeting.luau
```

The tree in `default.rogen.json` holds Rojo's sample Baseplate and the Lighting and SoundService settings, as `$properties` and a `Baseplate` node, and Rogen routes nothing in it.

## Getting Started
To build the place from scratch, use:

```bash
rogen build -o "project.rbxlx"
```

Next, open `project.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rogen serve
```

## Changing the project
Edit `default.rogen.json`, not `default.project.json`, which `rogen write` replaces. After you add a feature folder, run `rogen write` so the editor's `default.project.json` follows. The `routes` in the config say where each folder's code goes, and a folder to place as it is, such as `Packages`, is mounted in its `tree`.

For more help, check out [the Rogen documentation](https://rogen-roblox.vercel.app/).
