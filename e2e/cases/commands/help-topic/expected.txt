  # Layout
  
  - A `(Name)/` folder groups files on disk and is left out of the tree. `(Server)/` is still a routing folder.
  - A directory with an `init` script (`init.luau`, `init.server.luau`, roblox-ts's `index.ts`) is one instance: the script is the folder, and the other files in it are its children, each routed like any other file.
  - An init script's route (`init@server.luau`, or `init.server.luau` with a `server` key) routes its whole folder like a marker file.
  - A folder split across routes becomes an instance in each, and each gets a copy of its init ModuleScript with only the files routed there; an init Script is never copied. A copy's children depend on where it sits, not who runs it, and the server may load two copies, so keep a copied init stateless and use `script:FindFirstChild` rather than `RunService` to pick children.
  - An init script with no folder of its own to become, in a root dir or a plain routing folder, is an error.
  - A file's `.meta.json` is named after the name Rojo gives it: `Save.server.luau` takes `Save.meta.json`, and `^Animate.client.luau` takes `^Animate.meta.json`.
  - A feature folder's `init.meta.json` (`{ "className": "Actor" }`) applies to every node the folder becomes. In a governing routing folder or an invisible folder it applies to nothing, and Rogen warns. A `Name@key` folder and a routing folder an outer route outranks are ordinary folders.
  - A symlink or junction inside a root dir is read as the directory it points at, and keeps its own path in the output.

$ rogen help route.dotRoute

stdout:
  route.dotRoute
  
  Warning. A route key is written after a dot, where only `@` routes, so it routes nothing: a dot-file like `.server`, which isn't a marker, a dot-folder like `.server/`, which isn't a routing folder, or a dot part of a name like `Types.shared.luau` or `Net.server/`, which stays in the name. What it names falls through to the route above it, or `*`. The key matches in any letter case, so `.SERVER/` and `Types.SHARED.luau` warn too. Rojo's `.server` and `.client` at the end of a script still route and are never reported, but only in lower case (Rojo reads `Boot.Server.luau` as a ModuleScript named `Boot.Server`, so Rogen suggests `Boot.server.luau`), and only on a script: a data file or model has no script class, so `Config.server.json` is named `Config.server` and warns. One warning lists every such name.
  
    default.rogen.json - warning: 2 names write a route key after a dot, where only "@" routes, so they route nothing: (route.dotRoute)
      src/Inventory/.server (write "@server")
      src/Inventory/Types.shared.luau (write "Types@shared.luau")
  
  Rename each to its `@` form: a marker file is `@server`, a folder `@server/`, and a name `Types@shared.luau` or `Config@server.json`. In `--json`, `fixes` holds every rename. See Marker Files (https://rogen-playfully.vercel.app/docs/v2/core-concepts/routing#marker-files).
