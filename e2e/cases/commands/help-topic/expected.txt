  # Variants
  
  A variant swaps a file at build time. Declare every variant in `variants` with whether it is on: `"variants": { "mock": false }`. An undeclared dot part is just part of the name (`Save.spec.luau`), but one a single edit from a declared variant warns, in a name, a folder or a marker file (`Analytics.mok.luau`, `.mok/`, `.mok`). Variants are not Roblox instance Tags.
  
  - `Analytics.mock.luau` becomes `Analytics` while `mock` is on, replacing the plain file, and is left out while it is off. It combines with a route in either order (`Analytics.mock@server.luau`); Rojo's `.server` or `.client` stays last.
  - A variant folder (`mock/`) or marker file (`.mock`) marks everything inside. `dev/Service.luau` beside `prod/Service.luau` lets the active variant pick which file becomes `Service`. With both off, `Service` is missing, and Rogen warns.
  - `Analytics.mock/` carries the variant and keeps the name `Analytics`.
  - Only a dot carries a variant: `HttpMock.luau` and `Http-mock.luau` are ordinary names, and `Analytics@mock.luau` warns.
  - Two files with active variants at one name are an error; two plain files at one name are a warning.
  - `--variant mock` turns a variant on and `--no-variant mock` turns it off, for one run. They have no short flags. For a lasting choice, write a config that extends and flips it.
  - `rogen list` shows every config's variants with their state.

stdout:
  route.dotRoute
  
  Warning. A route key is written after a dot, where only `@` routes, so it routes nothing: a dot-file like `.server`, which isn't a marker, a dot-folder like `.server/`, which isn't a routing folder, or a dot part of a name like `Types.shared.luau` or `Net.server/`, which stays in the name. What it names falls through to the route above it, or `*`. The key matches in any letter case, so `.SERVER/` and `Types.SHARED.luau` warn too. Rojo's `.server` and `.client` at the end of a script still route and are never reported, but only in lower case (Rojo reads `Boot.Server.luau` as a ModuleScript named `Boot.Server`, so Rogen suggests `Boot.server.luau`), and only on a script: a data file or model has no script class, so `Config.server.json` is named `Config.server` and warns. One warning lists every such name.
  
    default.rogen.json - warning: 2 names write a route key after a dot, where only "@" routes, so they route nothing:
      src/Inventory/.server (write "@server")
      src/Inventory/Types.shared.luau (write "Types@shared.luau")
  
  Rename each to its `@` form: a marker file is `@server`, a folder `@server/`, and a name `Types@shared.luau` or `Config@server.json`. In `--json`, `fixes` holds every rename. See Marker Files (https://rogen-playfully.vercel.app/docs/v2/core-concepts/routing#marker-files).
