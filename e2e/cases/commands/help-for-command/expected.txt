$ rogen help build
exit 0
stdout:
  Writes default.project.json, and a file for each project, beside the rogen.json here or beside each named one.
  
  Usage:
    rogen build [project...] [options]
  
  Arguments:
    project  A folder with a rogen.json, a *.project.json path, or the name of a project of the rogen.json here. The rogen.json of the working directory, or of the nearest folder above it that has one, when none is given.
  
  Options:
        --json           Print one JSON document instead of text.
        --deny-warnings  Exit 1 when any config has a warning.
  
  Examples:
    rogen build
    rogen build places/lobby
    rogen build --json
    rogen build --deny-warnings
  
  Global options:
    -h, --help     Print help.
    -V, --version  Print the version.
    -v, --verbose  Print debug output.
    -q, --quiet    Only print errors.

$ rogen help init
exit 0
stdout:
  Writes a starting rogen.json, detecting the workspace and asking in a terminal.
  
  Usage:
    rogen init [options]
  
  Options:
    -y, --yes              Write the defaults without asking, as a run without a terminal, or under a coding agent or CI, does. --json implies it.
        --non-interactive  The same as -y: take every default without asking.
        --json             Print one JSON document instead of text.
  
  Examples:
    rogen init
    rogen init -y
    rogen init --non-interactive
  
  Global options:
    -h, --help     Print help.
    -V, --version  Print the version.
    -v, --verbose  Print debug output.
    -q, --quiet    Only print errors.
