$ rogen help build
exit 0
stdout:
  Writes default.project.json, and a file for each project, beside the rogen.json here or beside each named one; with -o or -p, also builds a place, model or plugin with Rojo.
  
  Usage:
    rogen build [project...] [options]
  
  Arguments:
    project  A folder with a rogen.json, a *.project.json path, or the name of a project of the rogen.json here. The rogen.json of the working directory, or of the nearest folder above it that has one, when none is given.
  
  Options:
        --json             Print one JSON document instead of text.
        --deny-warnings    Exit 1 when any config has a warning.
    -o, --output <output>  Also build the project into this place or model file with Rojo (.rbxl, .rbxlx, .rbxm or .rbxmx).
    -p, --plugin <plugin>  Also build the project into Roblox's plugins folder with Rojo, under this file name.
        --watch            Keep going: write the project files again whenever names or configs change, and build with Rojo after each write when -o or -p is given. Press Ctrl+C to stop; --json prints one JSON object per line.
  
  Examples:
    rogen build
    rogen build places/lobby
    rogen build -o game.rbxl
    rogen build --watch
    rogen build --watch -o game.rbxl
    rogen build --json
    rogen build --deny-warnings
  
  Global options:
    -h, --help     Print help.
    -V, --version  Print the version.
    -v, --verbose  Print debug output.
    -q, --quiet    Only print errors.

$ rogen help init
exit 0
stdout:
  Writes a starting rogen.json, detecting the workspace and asking in a terminal. With a folder below a config, adds it as a place of that config.
  
  Usage:
    rogen init [path] [options]
  
  Arguments:
    path  A folder below a rogen.json to add as a place of it: its own rogen.json with the port it is served on, its entry in the config's placePaths when none lists it, and a .code-workspace that lists the config's folder and every place.
  
  Options:
        --non-interactive  Write the defaults without asking, as a run without a terminal, or under a coding agent or CI, does. --json implies it.
        --json             Print one JSON document instead of text.
  
  Examples:
    rogen init
    rogen init --non-interactive
    rogen init places/lobby
  
  Global options:
    -h, --help     Print help.
    -V, --version  Print the version.
    -v, --verbose  Print debug output.
    -q, --quiet    Only print errors.
