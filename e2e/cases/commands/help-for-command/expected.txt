$ rogen help build
exit 0
stdout:
  Writes each named config's project file.
  
  Usage:
    rogen build [name...] [options]
  
  Arguments:
    name  A config to build.
  
  Options:
    -c, --config <value>    An explicit config path. (repeatable)
    -o, --out-file <value>  Overrides outFile.
    -s, --sync-dir <value>  Overrides syncDir.
        --template <value>  Overrides template.
    -t, --tag <value>       Turns a tag on. (repeatable)
        --no-tag <value>    Turns a tag off. (repeatable)
        --show-config       Prints the resolved config and exits.
  
  Global options:
    -h, --help     Print help.
    -v, --version  Print the version.
        --verbose  Print debug output.
    -q, --quiet    Only print errors.
