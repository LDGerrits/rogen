$ rogen help build
exit 0
stdout:
  Writes the project file of each config here, or of the named ones.
  
  Usage:
    rogen build [config...] [options]
  
  Arguments:
    config  A config's name (lobby for lobby.rogen.json) or path. Every config here when none is given.
  
  Options:
    -o, --out-file <path>    Overrides outFile, for one config.
        --variant <name>     Turns a variant on. (repeatable)
        --no-variant <name>  Turns a variant off. (repeatable)
        --json               Print one JSON document instead of text.
  
  Examples:
    rogen build
    rogen build places/lobby.rogen.json --variant mock
    rogen build --json
  
  Global options:
    -h, --help     Print help.
    -V, --version  Print the version.
    -v, --verbose  Print debug output.
    -q, --quiet    Only print errors.

$ rogen help init
exit 0
stdout:
  Writes a starting config, detecting the workspace and asking in a terminal.
  
  Usage:
    rogen init [name] [options]
  
  Arguments:
    name  The config to write. Defaults to default. Beside an existing default.rogen.json, a run that doesn't ask adds it as a place in places/<name>.
  
  Options:
    -y, --yes   Write the defaults without asking, as a run without a terminal, or under a coding agent or CI, does. --json implies it.
        --json  Print one JSON document instead of text.
  
  Examples:
    rogen init
    rogen init lobby
    rogen init -y
  
  Global options:
    -h, --help     Print help.
    -V, --version  Print the version.
    -v, --verbose  Print debug output.
    -q, --quiet    Only print errors.
