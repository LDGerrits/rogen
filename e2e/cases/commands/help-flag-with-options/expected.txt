$ rogen build --variant mock --help
exit 0
stdout:
  Writes the project file of each config here, or of the named ones.
  
  Usage:
    rogen build [config...] [options]
  
  Arguments:
    config  A config's name (lobby for lobby.rogen.json, wherever it is) or path. When none is given, every config here and each one below that extends one here, or those of the nearest folder above that has any.
  
  Options:
    -o, --out-file <path>    Overrides outFile, for one config.
        --mode <name>        Picks the mode every config that declares modes builds in.
        --variant <name>     Turns a variant on, beyond those the mode lists. (repeatable)
        --no-variant <name>  Turns a variant off, whatever turned it on. (repeatable)
        --json               Print one JSON document instead of text.
        --deny-warnings      Exit 1 when any config has a warning.
  
  Examples:
    rogen build
    rogen build places/lobby.rogen.json --variant mock
    rogen build --json
    rogen build --mode prod --deny-warnings
  
  Global options:
    -h, --help     Print help.
    -V, --version  Print the version.
    -v, --verbose  Print debug output.
    -q, --quiet    Only print errors.
