  rogen-build
  Writes the project file of default.rogen.json here, or of the config you name, beside it
  (dist.rogen.json writes dist.project.json); with -o or -p, also builds a place, model or plugin with
  Rojo.
  
  USAGE:
      rogen build [OPTIONS] [PROJECT]
  
  ARGS:
      <PROJECT>    A folder, a .rogen.json file, a *.project.json path, or the name of a file here. A
                   name such as dist stands for dist.rogen.json. The default.rogen.json of the working
                   directory, or its default.project.json, when none is given.
  
  OPTIONS:
          --color <COLOR>      Whether to colour the output. [default: auto] [possible values: auto,
                               always, never]
      -h, --help               Print help.
          --json               Print one JSON document instead of text.
      -o, --output <OUTPUT>    Also build the project into this place or model file with Rojo (.rbxl,
                               .rbxlx, .rbxm or .rbxmx).
      -p, --plugin <PLUGIN>    Also build the project into Roblox's plugins folder with Rojo, under
                               this file name.
      -q, --quiet              Only print errors.
      -v, --verbose            Print debug output; -vv, trace output. (repeatable)
      -V, --version            Print the version.
          --watch              Keep going: write the project file again whenever names or configs
                               change. With -o or -p, build with Rojo after each write, and again
                               after an edit inside a file under the source paths. Press Ctrl+C to
                               stop; --json prints one JSON object per line.
  
  EXIT CODES:
      0    done (warnings included)
      1    the project has a problem: an error, or Rojo failing
      2    the command line is wrong, or a terminal is needed and there is none
  
  EXAMPLES:
      rogen build
      rogen build places/lobby
      rogen build -o game.rbxl
      rogen build --watch
      rogen build --watch -o game.rbxl
      rogen build --json
