$ rogen help
exit 0
stdout:
  Rogen - Feature-based architecture for Roblox
  
  Usage:
    rogen [command] [name...] [options]
  
  Commands:
    build [project...]  Writes default.project.json beside the rogen.json here, or beside each named one.
    check [path...]     Prints the diagnostics about the given paths, or about the whole project, and exits 1 when there are any.
    help [name]         Prints usage, a command's details, a topic, or what a diagnostic code means.
    init                Writes a starting rogen.json, detecting the workspace and asking in a terminal.
    list [project...]   Lists every config here with its source paths, routes, sync path and project file; with --json, each fully resolved.
    serve [project...]  Builds, serves the project files with Rojo, and rebuilds whenever sources or configs change.
    watch [project...]  Builds, then rebuilds whenever sources or configs change.
    where [path...]     Prints where each file lands in the game, and why, with its warnings.
  
  Topics:
    routing  How folders and names place a file, and what that means for requires.
    config   Config fields, the tree, source paths and the sync path.
    layout   Invisible folders, init scripts and .meta.json files.
    output   Diagnostics, exit codes, --json, fixes and docs links.
  
  Options:
    -h, --help     Print help.
    -V, --version  Print the version.
    -v, --verbose  Print debug output.
    -q, --quiet    Only print errors.
  
  Run 'rogen help <command>' for details on a command, 'rogen help <topic>' to read a topic, and 'rogen help <code>' to explain a diagnostic code.
  
  Exit codes: 0 done (warnings included), 1 the project has errors, 2 the command line is wrong.
