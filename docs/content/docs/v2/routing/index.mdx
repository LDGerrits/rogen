---
title: How Routing Works
description: Name a folder or file after a route, and Rogen puts it where the route points
---

Your config's `routes` name the places your code can go in the game:

```json title="default.rogen.json"
{
	"routes": {
		"server": "ServerScriptService",
		"client": "StarterPlayer/StarterPlayerScripts",
		"shared": "ReplicatedStorage/Shared",
		"*": "ReplicatedStorage/Shared"
	}
}
```

A route's name in a file's path sends the file there. A `server/` folder sends everything inside it, and `@client` at the end of a name sends one file:

<RouteFigure
	disk={`
  src/
    shop/
      server/
        ShopService.luau
      shared/
        Prices.luau
      ShopUI@client.luau
`}
	studio={`
  ReplicatedStorage
    shared/
      shop/
        Prices
  ServerScriptService
    shop/
      ShopService
  StarterPlayer
    StarterPlayerScripts
      shop/
        ShopUI
`}
/>

Everything else in the path stays, so `shop` shows up under each service. The route's name must be spelled exactly as its key: a `Server/` folder or `save@Sever.luau` under a `server` route is an error, so a typo never sends server code somewhere else.

Each way to route has its own page: [Routing Folders](/docs/v2/routing/folders), [Routing by Name](/docs/v2/routing/names) and [Routing by Pattern](/docs/v2/routing/patterns). [Skipping Folders](/docs/v2/routing/skipping-folders) shows how to leave a folder out of the game.

## Files Without a Route

The `*` route takes every file that no other route matches, so `src/shop/Prices.luau` lands in `ReplicatedStorage/Shared/shop`. A [pattern route](/docs/v2/routing/patterns) such as `*.tsx` takes a file by its name before `*` does. `rogen init` writes it. Without `*`, Rogen leaves such a file out and warns about it, so a server file that forgets its route never reaches clients. That suits a project where every file names its side.

## The Outermost Route Wins

A route inside another route is an ordinary folder. Server code under `shared/` ships to every client, and Rogen warns about it:

<RouteFigure
	disk={`
  src/
    shared/
      server/
        Datastore.luau
`}
	studio={`
  ReplicatedStorage
    shared/
      server/
        Datastore
`}
/>

## Check Where a File Lands

`rogen where` prints where a file lands in the game, and the require that reaches it:

```
$ rogen where src/shop/server/ShopService.luau
src/shop/server/ShopService.luau -> ServerScriptService/shop/ShopService · route server (folder)
  require(game:GetService("ServerScriptService").shop.ShopService)
```
