---
title: Routing by Name
description: Route a file or folder without moving it into a routing folder
---

When a feature is too small for routing folders, route by name instead.

## The `@` Suffix

`@` and a route key at the end of a file or folder name route it, and come off the name. A file keeps its class, so `TradeService@Server.luau` stays a ModuleScript:

<RouteFigure
	disk={`
  src/
    Trade/
      Admin@Server/
        Ban.luau
      TradeService@Server.luau
      TradeTypes@Shared.luau
      TradeUi@Client.luau
`}
	studio={`
  ReplicatedStorage
    Shared/
      Trade/
        TradeTypes
  ServerScriptService
    Trade/
      Admin/
        Ban
      TradeService
  StarterPlayer
    StarterPlayerScripts
      Trade/
        TradeUi
`}
/>

## Marker Files

An empty file named `@Server` routes the folder it's in, and the folder keeps its name:

<RouteFigure
	disk={`
  src/
    Anticheat/
      @Server
      Check.luau
      Report.luau
`}
	studio={`
  ServerScriptService
    Anticheat/
      Check
      Report
`}
/>

## Rojo's Script Suffixes

When your config has a `Server` or `Client` key, Rojo's `.server` and `.client` suffixes route a script as well as set its class, so `Main.server.luau` goes to the server. A sync rule's `suffix` routes another language's scripts the same way, such as `.server.lang`.

## Init Scripts

A route in an init script's name places only the script, not the folder around it; to move the whole folder, route the folder itself. That lets each side have its own init script:

<RouteFigure
	disk={`
  src/
    Shop/
      init@Server.luau
      init@Client.luau
      ShopService@Server.luau
      ShopUi@Client.luau
`}
	studio={`
  ServerScriptService
    Shop
      ShopService
  StarterPlayer
    StarterPlayerScripts
      Shop
        ShopUi
`}
/>

## Patterns

A route key with a `*` is a pattern on file names, where `*` stands for any run of characters. It matches a file's name or the name of the instance it makes, so `*Controller` and `*Controller.*` both take `ShopController.luau`. It takes a file that no folder, `@` or marker routes, so a project that names files by their role needs no `@` on each one:

```json title="default.rogen.json"
{
	"routes": {
		"Server": "ServerScriptService",
		"Client": "StarterPlayer/StarterPlayerScripts",
		"Shared": "ReplicatedStorage/Shared",
		"*Controller.*": "StarterPlayer/StarterPlayerScripts",
		"*Service.*": "ServerScriptService",
		"*": "ReplicatedStorage/Shared"
	}
}
```

<RouteFigure
	disk={`
  src/
    Shop/
      ShopController.luau
      ShopService.luau
      Prices.luau
      Shared/
        PriceService.luau
`}
	studio={`
  ReplicatedStorage
    Shared/
      Shop/
        PriceService
        Prices
  ServerScriptService
    Shop/
      ShopService
  StarterPlayer
    StarterPlayerScripts
      Shop/
        ShopController
`}
/>

A pattern keeps the whole name, so `ShopController.luau` stays `ShopController`, and a route you write always beats it, which is why `PriceService` stays in its `Shared/` folder. A pattern never matches a folder, nor an init script, which is its folder, so a script written as `InputController/init.luau` stays with its children; route that folder by its name, as `InputController@Client/`. When several patterns match, the one with more characters that aren't `*` wins, so `*.story.tsx` beats `*.tsx` and every pattern beats `*`; a tie between different places is [`route.patternClash`](/docs/v2/diagnostics#route-patternclash). Patterns match letter case exactly and never a path, and a misspelt name such as `ShopControler.luau` simply falls to `*`.
