---
title: Routing by Name
description: Route a file or folder without moving it into a routing folder
---

When a feature is too small for routing folders, route by name instead.

## The `@` Suffix

`@` and a route key at the end of a file or folder name route it, and come off the name. A file keeps its class, so `trade-service@server.luau` stays a ModuleScript:

<RouteFigure
	disk={`
  src/
    trade/
      admin@server/
        ban.luau
      trade-service@server.luau
      trade-types@shared.luau
      trade-ui@client.luau
`}
	studio={`
  ReplicatedStorage
    shared/
      trade/
        trade-types
  ServerScriptService
    trade/
      admin/
        ban
      trade-service
  StarterPlayer
    StarterPlayerScripts
      trade/
        trade-ui
`}
/>

## Marker Files

An empty file named `@server` routes the folder it's in, and the folder keeps its name:

<RouteFigure
	disk={`
  src/
    anticheat/
      @server
      check.luau
      report.luau
`}
	studio={`
  ServerScriptService
    anticheat/
      check
      report
`}
/>

## Rojo's Script Suffixes

When your config has a `server` or `client` key, Rojo's `.server` and `.client` suffixes route a script as well as set its class, so `main.server.luau` goes to the server. A sync rule's `suffix` routes another language's scripts the same way, such as `.server.lang`.

## Init Scripts

A route in an init script's name places only the script, not the folder around it; to move the whole folder, route the folder itself. That lets each side have its own init script:

<RouteFigure
	disk={`
  src/
    shop/
      init@server.luau
      init@client.luau
      shop-service@server.luau
      shop-ui@client.luau
`}
	studio={`
  ServerScriptService
    shop
      shop-service
  StarterPlayer
    StarterPlayerScripts
      shop
        shop-ui
`}
/>

A plain `init.luau` routes the same way: it is its folder only where its own route puts it, which is `*` unless something routes it. On every other side the folder's files sit in a plain folder of the same name, so the init script reaches a server-only child by its full path, as `ServerScriptService.shop["shop-service"]`, rather than through `script`.
