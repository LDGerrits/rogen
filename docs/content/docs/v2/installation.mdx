You can install Rogen with **Rokit** or **npm**.

<Callout type="info">
	Rogen only writes the project file. The syncing is done by
	[Rojo](https://github.com/rojo-rbx/rojo) or
	[Argon](https://github.com/argon-rbx/argon), so you'll need one of those too,
	with its Studio plugin. `rogen serve` starts the one your project pins (for
	example with `rokit add rojo-rbx/rojo`), else the one on the PATH. It never
	installs one.
</Callout>

<Tabs items={["Rokit", "npm"]}>
  <Tab value="Rokit">
    <Steps>
      <Step>
        ### Add Rogen to Rokit

        Add Rogen to your `rokit.toml`:

        ```toml title="rokit.toml"
        [tools]
        rogen = "ldgerrits/rogen@2.0.0"
        ```

      </Step>

      <Step>
        ### Install

        ```bash
        rokit install
        ```

      </Step>

      <Step>
        ### Check It Works

        ```bash
        rogen --version
        ```

        If this prints a version number, you're set.

      </Step>
    </Steps>

  </Tab>

  <Tab value="npm">
    <Steps>
      <Step>
        ### Install

        Add Rogen to your project:

        ```bash
        npm i @ldgerrits/rogen
        ```

      </Step>

      <Step>
        ### Check It Works

        Run the local install through `npx`:

        ```bash
        npx rogen --version
        ```

        If this prints a version number, you're set.

      </Step>
    </Steps>

  </Tab>
</Tabs>

## Next

Run `rogen init` in your project to get a starting config, then follow the [Luau](/docs/v2/setups/luau) or [roblox-ts](/docs/v2/setups/roblox-ts) guide.
