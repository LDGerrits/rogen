Rogen writes the Rojo project file, and [Rojo](https://rojo.space) syncs it into Studio, so a project needs both. Install Rogen with **Rokit** or **npm**:

<Tabs items={["Rokit", "npm"]}>
  <Tab value="Rokit">
    Add Rogen to your `rokit.toml`:

    ```toml title="rokit.toml"
    [tools]
    rogen = "ldgerrits/rogen@2.0.0-beta.1"
    ```

    Then install it, and check that it runs:

    ```bash
    rokit install
    rogen --version
    ```

  </Tab>

  <Tab value="npm">
    ```bash
    npm i @ldgerrits/rogen@next
    npx rogen --version
    ```

    Run every `rogen` command on these pages through `npx`.

  </Tab>
</Tabs>

## Rojo

For a new game, `rogen init` pins Rojo for you, as [Creating a New Game](/docs/v2/new-game) shows. In an existing project, update Rojo to 7.5.0 or newer, then install the Studio plugin that matches it:

```bash
rogen plugin install
```
