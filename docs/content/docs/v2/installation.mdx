You can install Rogen with **Rokit** or **npm**.

<Callout type="info">
	Rogen only writes the project file. The syncing is done by
	[Rojo](https://github.com/rojo-rbx/rojo), so you'll need it too, with its
	Studio plugin. `rogen serve` starts the Rojo your project pins (for example
	with `rokit add rojo-rbx/rojo`), else the one on the PATH, and checks its
	version first: sync rules need Rojo 7.5.0 or newer. It never installs one. To
	use Argon instead, see [Studio](/docs/v2/studio#serve-with-argon).
</Callout>

<Tabs items={["Rokit", "npm"]}>
  <Tab value="Rokit">
    <Steps>
      <Step>
        ### Add Rogen to Rokit

        Add Rogen to your `rokit.toml`:

        ```toml title="rokit.toml"
        [tools]
        rogen = "ldgerrits/rogen@2.0.0"
        ```

      </Step>

      <Step>
        ### Install

        ```bash
        rokit install
        ```

      </Step>

      <Step>
        ### Check It Works

        ```bash
        rogen --version
        ```

        If this prints a version number, you're set.

      </Step>
    </Steps>

  </Tab>

  <Tab value="npm">
    <Steps>
      <Step>
        ### Install

        Add Rogen to your project:

        ```bash
        npm i @ldgerrits/rogen
        ```

      </Step>

      <Step>
        ### Check It Works

        Run the local install through `npx`:

        ```bash
        npx rogen --version
        ```

        If this prints a version number, you're set.

      </Step>
    </Steps>

  </Tab>
</Tabs>

## Updates

Rogen tells you when a newer stable release is out, with one line on stderr after a command run in a terminal, and says which pin or `npm` command to change. To stop it, set `ROGEN_NO_UPDATE_CHECK=1` or `NO_UPDATE_NOTIFIER=1`. It reads GitHub's list of releases once a day. See [Update notice](/docs/v2/cli#update-notice) for when it speaks and what it keeps.
