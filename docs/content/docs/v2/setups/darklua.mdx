[Darklua](https://github.com/seaofvoices/darklua) rewrites your code into a folder of its own, the **sync directory**, and Rojo syncs from there. Rogen still reads your source to decide where files go; it just points Rojo's paths at the sync directory.

<Steps>

<Step>
### Define the Sync Directory

This guide assumes Darklua reads `src` and writes `dist`. With roblox-ts, it reads the compiled `out` folder instead.

</Step>

<Step>
### Create the Config

Run `rogen init`. It spots your `.darklua.json` and asks whether Darklua processes your code.

<Tabs items={["Luau", "roblox-ts"]} groupId="language" persist>
  <Tab value="Luau">
    `init` writes **two** configs. `default.rogen.json` holds the tree, with paths into `src`, and `sync.rogen.json` extends it with the sync directory:

    ```json title="default.rogen.json"
    {
    	"$schema": "https://ldgerrits.github.io/rogen/schema/2/rogen.json",
    	"rootDirs": ["src"],
    	"routes": {
    		"Server": "ServerScriptService",
    		"Client": "StarterPlayer/StarterPlayerScripts",
    		"Shared": "ReplicatedStorage/Shared",
    		"*": "ReplicatedStorage/Shared"
    	}
    }
    ```

    ```json title="sync.rogen.json"
    {
    	"$schema": "https://ldgerrits.github.io/rogen/schema/2/rogen.json",
    	"extends": "./default.rogen.json",
    	"syncDir": "dist"
    }
    ```

    That's one tree rendered twice: `default.project.json` points into `src`, and `sync.project.json` into `dist`, which is the one you serve.

    The source-facing config is the default because luau-lsp builds `sourcemap.json` from `default.project.json`, and Darklua's `convert_require` reads that same sourcemap. Your editor and Darklua both see your real source, with nothing to configure.

  </Tab>
  <Tab value="roblox-ts">
    `init` writes **one** config. `rbxtsc` compiles `src` into `out`, and Darklua processes `out` into the sync directory:

    ```json title="default.rogen.json"
    {
    	"$schema": "https://ldgerrits.github.io/rogen/schema/2/rogen.json",
    	"rootDirs": ["src"],
    	"routes": {
    		"server": "ServerScriptService",
    		"client": "StarterPlayer/StarterPlayerScripts",
    		"shared": "ReplicatedStorage/shared",
    		"*": "ReplicatedStorage/shared"
    	},
    	"template": "template.project.json",
    	"syncDir": "dist"
    }
    ```

    roblox-ts has its own types, so one config is enough.
  </Tab>
</Tabs>

</Step>

<Step>
### Run the Pipeline

`init` prints the commands to run side by side.

<Tabs items={["Luau", "roblox-ts"]} groupId="language" persist>
  <Tab value="Luau">
    ```
    Have Darklua process your code into the sync dir:
      darklua process src dist
    ```

    With several root directories, `init` prints one command each (`darklua process lib dist/lib`).

    ```bash
    darklua process src dist --watch
    ```

    Watch both configs, so Darklua's project file stays current too:

    ```bash
    rogen watch default sync
    ```

    luau-lsp keeps `sourcemap.json` current while your editor is open. Without it, run:

    ```bash
    rojo sourcemap default.project.json --output sourcemap.json --watch
    ```

    Then serve the synced project:

    ```bash
    rojo serve sync.project.json
    ```

    <Callout type="warn">
    	A bare `rojo serve` picks up `default.project.json` and syncs unprocessed source. Always pass `sync.project.json`.
    </Callout>
  </Tab>
  <Tab value="roblox-ts">
    ```
    Have Darklua process your code into the sync dir:
      darklua process out dist
    ```

    ```bash
    rbxtsc -w
    darklua process out dist --watch
    rogen watch
    ```

    Then start Rojo with `rojo serve`.
  </Tab>
</Tabs>

</Step>

</Steps>

<Callout type="info">
	`rogen build` and `rogen watch` mention any config you didn't ask for, so you'll notice if you forget the sync config.
</Callout>

## Data Files

Darklua turns `.txt`, `.json`, `.toml`, `.yaml` and `.yml` files into Lua modules (`src/Note.txt` becomes `dist/Note.lua`) and drops `.csv` files. Rogen still points at `dist/Note.txt`, so the instance goes missing, and Rogen warns:

```
default.rogen.json - warning: 1 data file was turned into a Lua module under "dist" (src/Note.txt: expected "dist/Note.txt", found "dist/Note.lua"). (output.dataFileConverted)
```

Either require the module (`require(script.Parent.Note)` returns the string), or copy the data files into `dist` after Darklua runs.
