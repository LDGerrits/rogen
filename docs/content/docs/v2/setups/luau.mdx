Rogen builds Luau projects directly. There's no compiler, so Rojo syncs the root directories themselves and no sync directory is needed.

<Steps>

<Step>
### Create the Config

Run the initialization command in the project root:

```bash
rogen init
```

It writes `default.rogen.json` and prints what to do next:

```
Created default.rogen.json.
Next steps
  rogen watch
  rojo serve default.project.json
  Add your own routes under "routes" in default.rogen.json.
  Add tags under "tags" in default.rogen.json to swap in variants like Analytics.mock.luau.
```

```json title="default.rogen.json"
{
	"$schema": "https://rogen.dev/schema/2/rogen.json",
	"rootDirs": ["src"],
	"routes": {
		"Server": "ServerScriptService",
		"Client": "StarterPlayer/StarterPlayerScripts",
		"Shared": "ReplicatedStorage/Shared",
		"*": "ReplicatedStorage/Shared"
	}
}
```

In a terminal, `init` asks about the root directories, the routes and where files that match no route go. Pressing Enter at every question writes the config above. If it finds installed Wally or Pesde packages, it offers to mount them and writes a `template.project.json` for them.

</Step>

<Step>
### Lay Out a Feature

Put each feature in a folder under `src`, with a routing folder per side:

```
src/Inventory/Server/InventoryService.luau
src/Inventory/Client/InventoryController.luau
src/Inventory/Shared/InventoryTypes.luau
```

Rogen sends them to `ServerScriptService/Inventory`, `StarterPlayer/StarterPlayerScripts/Inventory` and `ReplicatedStorage/Shared/Inventory`. See [Routing](/docs/v2/core-concepts/routing).

</Step>

<Step>
### Start Watching

Run Rogen in watch mode. Rogen builds `default.project.json` and updates it when files change.

```bash
rogen watch
```

</Step>

<Step>
### Sync with Rojo

Open a separate terminal window and start Rojo with the generated project file.

```bash
rojo serve
```

</Step>

</Steps>

<Callout type="info">
	`rojo serve` with no argument picks up `default.project.json`, which is the file `rogen watch` writes.
</Callout>
