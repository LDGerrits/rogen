Luau is the simplest setup. There's no compiler, so Rojo syncs straight from your source and you don't need a sync directory.

<Steps>

<Step>
### Create the Config

In the project root, run:

```bash
rogen init
```

It writes `default.rogen.json` and tells you what to do next:

```
Created default.rogen.json.
Next steps
  Run each in its own terminal:
    rogen watch
    rojo serve default.project.json
  Add your own routes under "routes" in default.rogen.json.
  Declare variants under "variants" in default.rogen.json to swap in files like Analytics.mock.luau.
```

```json title="default.rogen.json"
{
	"$schema": "https://ldgerrits.github.io/rogen/schema/2/rogen.json",
	"rootDirs": ["src"],
	"routes": {
		"Server": "ServerScriptService",
		"Client": "StarterPlayer/StarterPlayerScripts",
		"Shared": "ReplicatedStorage/Shared",
		"*": "ReplicatedStorage/Shared"
	}
}
```

In a terminal, `init` asks about your root directories, your routes and where files that match no route should go. Press Enter at every question to get the config above. If it finds Wally or Pesde, it offers to mount their package folders (as optional, so nothing breaks before you install) in a new `template.project.json`. If you already have a hand-written `default.project.json`, it copies that to `template.project.json` instead, so you don't lose anything.

</Step>

<Step>
### Lay Out a Feature

Give each feature a folder under `src`, with a routing folder per side:

```
src/Inventory/Server/InventoryService.luau
src/Inventory/Client/InventoryController.luau
src/Inventory/Shared/InventoryTypes.luau
```

Rogen puts these in `ServerScriptService/Inventory`, `StarterPlayer/StarterPlayerScripts/Inventory` and `ReplicatedStorage/Shared/Inventory`. [Routing](/docs/v2/core-concepts/routing) explains the details.

</Step>

<Step>
### Start Watching

Start Rogen in watch mode. It builds `default.project.json` and keeps it up to date as you add, move and rename files.

```bash
rogen watch
```

</Step>

<Step>
### Sync with Rojo

In a second terminal, start Rojo:

```bash
rojo serve
```

</Step>

</Steps>

<Callout type="info">
	With no argument, `rojo serve` picks up `default.project.json`, which is exactly the file `rogen watch` writes.
</Callout>
