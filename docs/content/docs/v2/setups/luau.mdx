## The Editor

luau-lsp builds its sourcemap from `default.project.json`, which git ignores. After you clone, run `rogen write`, then **Luau: Regenerate Sourcemap**. A new feature folder reaches the sourcemap when `rogen serve` or `rogen write` updates the project file.

## Requires

A Luau `require` names where the module is in the game, not where the file is on disk, and `rogen where <file>` prints it. A string require such as `require("./Prices")` resolves in the game too, so it reaches only the files routed into the same folder.

## Using Darklua

[Darklua](https://github.com/seaofvoices/darklua) rewrites `src` into `dist`, and its `convert_require` rule turns path requires into instance requires using `sourcemap.json`:

```json title=".darklua.json"
{
	"rules": [
		{
			"rule": "convert_require",
			"current": { "name": "path" },
			"target": {
				"name": "roblox",
				"rojo_sourcemap": "sourcemap.json",
				"indexing_style": "wait_for_child"
			}
		}
	]
}
```

This needs two configs: `default.rogen.json` for the sourcemap, and `dist.rogen.json`, a copy with `"compiledPath": "dist"` and a `name`, for serving. Keep the two in step. `rogen init` writes both for a Rojo project that already uses Darklua.

Run each in its own terminal, in this order:

```bash
rogen sourcemap --watch -o sourcemap.json
darklua process src dist --watch
rogen serve dist
```

For a release, run each once, with `rogen build dist -o game.rbxl` last.
