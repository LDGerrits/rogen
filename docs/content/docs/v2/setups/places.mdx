---
title: Several Places
description: Set up Rogen for a game with more than one place
---

A game with a lobby and a match is two places that share code. In Rogen, each place has a config of its own, and the shared code is a plain folder that each place lists in its `sourcePaths`.

## Start a Game with Places

In an empty folder, run:

```bash
rogen init --places
```

It writes a first place, `game`, with its code in `src/game` and the shared code in `src/common`:

```json title="game.rogen.json"
{
	"name": "game",
	"sourcePaths": ["src/common", "src/game"],
	"routes": {
		"Server": "ServerScriptService",
		"Client": "StarterPlayer/StarterPlayerScripts",
		"Shared": "ReplicatedStorage/Shared",
		"*": "ReplicatedStorage/Shared"
	},
	"tree": { "$className": "DataModel" }
}
```

A place's file replaces a shared file at the same path, because the later source path wins.

## Name the Place

There is no `default.rogen.json`, so name the place in each command:

```bash
rogen serve game
rogen build game -o game.rbxl
```

## Add a Place

Copy the first place's config, set its `"name"` to `"lobby"` and its own folder in `sourcePaths`, and make that folder:

```bash
cp game.rogen.json lobby.rogen.json
mkdir src/lobby
```

To serve two places at once, give the second a port of its own with `--port`, or set Rojo's `servePort` in its config.
