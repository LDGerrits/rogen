---
title: Multi-Place Games
description: Set up Rogen for a game with more than one place
---

Each place has a config of its own. Shared code is a plain folder that each place lists in its `sourcePaths`; a place's own file replaces a shared one at the same path.

## Start a Game with Places

In an empty folder, run:

```bash
rogen init --places
```

It writes a first place, `game`, with its code in `src/game` and shared code in `src/common`:

```json title="game.rogen.json"
{
	"name": "game",
	"sourcePaths": ["src/common", "src/game"],
	"routes": {
		"Server": "ServerScriptService",
		"Client": "StarterPlayer/StarterPlayerScripts",
		"Shared": "ReplicatedStorage/Shared",
		"*": "ReplicatedStorage/Shared"
	},
	"tree": { "$className": "DataModel" }
}
```

There is no `default.rogen.json`, so name the place in each command:

```bash
rogen serve game
rogen build game -o game.rbxl
```

## Add a Place

Copy the config, set `"name"` to `"lobby"`, and point `sourcePaths` at `src/lobby`. With the sample, also copy `place/game` and point the tree's `$path`s at `place/lobby`:

```bash
cp game.rogen.json lobby.rogen.json
mkdir src/lobby
cp -r place/game place/lobby
```

To serve two places at once, give the second its own `--port`.

## Places in roblox-ts

`rogen init --places --language roblox-ts` puts each place in `projects/<name>`, with its own `default.rogen.json` and `tsconfig.json`, and shared code in `projects/common/src`. Name the folder in each command, as in `rogen serve projects/game`.

To add a place, copy `default.rogen.json`, `tsconfig.json` and any `place` folder from `projects/game` into `projects/lobby`, make `projects/lobby/src`, and set `"name"` to `"lobby"`. Run `rogen write projects/lobby`, and add `rbxtsc -p projects/lobby` to the `build` and `watch` scripts in `package.json`, with `-w` for `watch`.
