With [roblox-ts](https://roblox-ts.com/), Rogen reads your uncompiled `src` folder to decide where each file goes, then writes paths into the compiled output, with `.ts` swapped for `.luau`. `rbxtsc` and `rojo serve` both read that same project file.

<Steps>

<Step>
### Create the Config

In the project root, run `init`. It recognizes roblox-ts from your `tsconfig.json`:

```bash
rogen init
```

```
Syncing from out, where roblox-ts compiles to.
Created template.project.json.
Created default.rogen.json.
Next steps
  Run each in its own terminal:
    rbxtsc -w
    rogen watch
    rojo serve default.project.json
  Add your own routes under "routes" in default.rogen.json.
  Declare variants under "variants" in default.rogen.json to swap in files like Analytics.mock.ts.
```

```json title="default.rogen.json"
{
	"$schema": "https://ldgerrits.github.io/rogen/schema/2/rogen.json",
	"rootDirs": ["src"],
	"routes": {
		"server": "ServerScriptService",
		"client": "StarterPlayer/StarterPlayerScripts",
		"shared": "ReplicatedStorage/shared",
		"*": "ReplicatedStorage/shared"
	},
	"template": "template.project.json",
	"syncDir": "out"
}
```

The `syncDir` comes from the `outDir` in `tsconfig.json` (or `out` if that isn't set), and the template mounts `include` and `node_modules/@rbxts` the way roblox-ts projects expect.

</Step>

<Step>
### Lay Out a Feature

roblox-ts projects use lowercase routing folders:

```
src/Inventory/server/InventoryService.ts
src/Inventory/client/InventoryController.ts
src/Inventory/shared/InventoryTypes.ts
```

Rogen puts these in `ServerScriptService/Inventory`, `StarterPlayer/StarterPlayerScripts/Inventory` and `ReplicatedStorage/shared/Inventory`, with paths pointing into `out/Inventory/…`.

</Step>

<Step>
### Run the Pipeline

`rbxtsc` and Rogen need to run side by side. One easy way to do that is with `concurrently`:

```bash
npm install -D concurrently
```

Add a script to `package.json` that starts both watchers:

```json
"scripts": {
	"watch": "concurrently \"rogen watch\" \"rbxtsc -w\""
}
```

Run it, and start Rojo in a second terminal:

```bash
npm run watch
rojo serve
```

</Step>

</Steps>

<Callout type="info">
	Every path Rogen writes is optional, so the project file still works on a fresh checkout before `rbxtsc` has created `out`.
</Callout>
