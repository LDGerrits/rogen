---
title: Coming from Rojo
description: Move a Rojo project to Rogen
---

This guide is being rewritten for Rogen 2. Until it's back, run `rogen init` in your Rojo project. It lifts your `default.project.json` into a `default.rogen.json` and keeps your tree. The source path is the closest folder that holds the code the project file mounts, such as `code` for `code/server` and `code/client`. Each of those folders becomes a route. Folders mounted from the top of the project, such as `server/`, stay in the tree. `init` warns about code that it places nowhere ([`init.codeOutsideSourcePaths`](/docs/v2/diagnostics#init-codeoutsidesourcepaths)). After that, make your changes in `default.rogen.json`, because `rogen write` writes `default.project.json` from it. If Darklua writes your code to a folder such as `build`, `init` also writes a `dist.rogen.json` for that folder. Serve it with `rogen serve dist`.
