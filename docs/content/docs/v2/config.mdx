---
title: Config
description: The keys Rogen adds to a Rojo project file
---

A config, `default.rogen.json`, is a Rojo project file with three more keys. Rogen writes it to `default.project.json` with your routed files added to [the tree](/docs/v2/routing/tree), so edit the config, never the project file. A second config, `X.rogen.json`, writes `X.project.json` and needs its own `name`. Rojo's own keys work as [Rojo documents them](https://rojo.space/docs/v7/project-format/).

| Key | Default | What it does |
|---|---|---|
| `routes` | none | [Route keys](/docs/v2/routing), names or [file-name patterns](/docs/v2/routing/patterns), and their targets. |
| `sourcePaths` | `["src"]` | The folders Rogen reads. A later folder's file replaces an earlier one's at the same path. |
| `compiledPath` | none | The folder a compiler such as [roblox-ts](/docs/v2/roblox-ts) or [Darklua](/docs/v2/luau#darklua) writes your code to, such as `out`. Rogen still reads the source paths to decide where each file goes, and points the project file at the compiled copy of the file in this folder, so Rojo syncs what the compiler wrote. The source paths keep their layout below their common folder, so set the compiler's `rootDir` to that folder. |

## Routes

A route key is letters and digits starting with a letter, or `*` for the [fallback route](/docs/v2/routing#files-without-a-route). Its target starts with a service, such as `"ServerScriptService"`, and may add folders, such as `"ReplicatedStorage/shared"`. Write `StarterPlayer/StarterPlayerScripts` in full, because Rogen doesn't know a service's children.

## Leaving Files Out

Rojo's `globIgnorePaths` lists globs, relative to the config, for files that Rojo ignores, and Rogen doesn't route them or warn about them:

```json title="default.rogen.json"
{
	"globIgnorePaths": ["**/*.spec.luau"]
}
```
