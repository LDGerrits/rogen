---
title: Using roblox-ts
description: Compile with roblox-ts while Rogen routes your TypeScript files
---

[roblox-ts](https://roblox-ts.com/) compiles the TypeScript in `src` to Luau in `out`. Rogen routes by the files in `src`, and Rojo syncs the compiled files in `out`.

## Start a Project

Start a new project with the command below. In a folder that already has a `tsconfig.json`, a bare `rogen init` sets Rogen up beside it instead.

```bash
rogen init --language roblox-ts
```

## Compile and Serve

`rbxtsc` reads the project file, so on a fresh clone run `rogen write` before the first compile. After that, run each command in its own terminal:

```bash
npm run watch
rogen serve
```

## Several Places

With `rogen init --places --language roblox-ts`, each place is a folder under `projects` with a `tsconfig.json` of its own, and the `build` and `watch` scripts compile through a `tsconfig.<place>.json` at the root. [Multi-Place Games](/docs/v2/multi-place#places-in-roblox-ts) shows the files and why they are laid out so.

## Add a Feature

The routes that `init` writes for roblox-ts are lowercase. Code imports by relative file path, as in any TypeScript project:

## Packages

Packages in `@rbxts` reach the game by themselves. Another scope, such as `@rbxts-js` for React, needs a mount of its own, and with pnpm the scopes must be hoisted side by side, such as with `publicHoistPattern: ["@rbxts*"]` in `pnpm-workspace.yaml`:

```json title="default.rogen.json"
"node_modules": {
	"$className": "Folder",
	"@rbxts": { "$path": "node_modules/@rbxts" },
	"@rbxts-js": { "$path": "node_modules/@rbxts-js" }
}
```
