---
title: Sync Details
description: How init scripts, meta files and data files sync
---

Routing decides where a file goes. This page covers the files that become something other than one instance of their own. The examples use the routes from [How Routing Works](/docs/v2/core-concepts/routing).

## Init Folders

A folder with an `init` script, such as `init.luau`, `init.server.luau` or roblox-ts's `index.ts`, is one instance, as in Rojo. The script is the folder, and the other files in it are its children:

<RouteFigure
	disk={`
  src/
    Inventory/
      init.luau
      Slots.luau
`}
	studio={`
  ReplicatedStorage
    Shared/
      Inventory
        Slots
`}
/>

A route on the init script, such as `init@Server.luau`, routes its whole folder, as a [marker file](/docs/v2/core-concepts/routing/names#marker-files) does.

When a folder's files land in two services, the folder becomes an instance in each, and each gets a copy of its `init.luau` with only the files routed there:

<RouteFigure
	disk={`
  src/
    Combat/
      Server/
        Damage.luau
      Shared/
        Weapons.luau
      init.luau
`}
	studio={`
  ReplicatedStorage
    Shared/
      Combat
        Weapons
  ServerScriptService
    Combat
      Damage
`}
/>

## Meta Files

A `.meta.json` file sets what a file can't set on its own, as in Rojo. Name it after the name Rojo gives the file: `Save.server.luau` takes `Save.meta.json`, and `TradeService@Server.luau` takes `TradeService@Server.meta.json`. A folder's `init.meta.json` applies to every instance the folder becomes.

## Data Files

Data files and models become instances as Rojo reads them, and route like scripts. Put the route before the extension, as in `Prices@Shared.json`.

## Leaving Files Out

`globIgnorePaths` lists globs, relative to the config, for files that Rojo ignores. Rogen doesn't route them or warn about them:

```json title="default.rogen.json"
{
	"globIgnorePaths": ["**/*.spec.luau"]
}
```
