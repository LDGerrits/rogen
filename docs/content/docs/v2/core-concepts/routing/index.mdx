---
title: Routing
description: How Rogen decides where each file lands in the game.
---

Rogen places each file by its folder and file names. The `routes` in your [config](/docs/v2/config) map each **route key** to a **target** in the game:

```json title="default.rogen.json"
{
	"routes": {
		"Server": "ServerScriptService",
		"Client": "StarterPlayer/StarterPlayerScripts",
		"Shared": "ReplicatedStorage/Shared"
	}
}
```

`rogen init` writes these three. Add your own the same way, such as `"Character": "StarterPlayer/StarterCharacterScripts"`.

## Routing Folders

A folder named after a route key sends everything inside it to that route's target. Give each feature a folder, with one routing folder per side:

		<TreeFolder name="Shared" level={2} dim />
		<TreeFile name="ShopItems.luau" level={3} />

The routing folder disappears, and the feature folder stays. A key's first letter matches either case, so roblox-ts's lowercase `server/` works too.

## Nested Routes

The outermost route wins. A `Server/` folder inside `Shared/` is an ordinary folder, so its code ships to every client:

| On disk | In the game |
|---|---|
| `src/Shared/Server/Datastore.luau` | `ReplicatedStorage/Shared/Server/Datastore` |

Rogen warns when this happens.

## Files Outside Every Route

Rogen leaves out a file that no route covers, and warns about it. It never guesses a side, so server code can't reach clients by accident.

To send those files somewhere instead, declare the fallback route `*`:

```json
"*": "ReplicatedStorage/Shared"
```

A server file that forgets its route then ships to clients without a warning, so declare `*` only when most of your code runs on both sides.

## See Where a File Lands

`rogen where` works before the file exists:

```
$ rogen where src/Shop/Server/ShopService.luau
src/Shop/Server/ShopService.luau -> ServerScriptService/Shop/ShopService · route Server (folder)
  require(game:GetService("ServerScriptService").Shop.ShopService)
```

## Other Ways to Route

| To | Use |
|---|---|
| Route one file or folder by its name | [`Save@Server.luau`, a marker file, or `.server`](/docs/v2/core-concepts/routing/names) |
| Put an instance at the top of its target | [`^Animate.client.luau`](/docs/v2/core-concepts/routing/top-level) |
