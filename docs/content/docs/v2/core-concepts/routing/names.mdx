---
title: Routing by Name
description: Route one file or folder with @, a marker file, or Rojo's script suffixes.
---

When a feature is too small for a folder per side, route by name.

## The `@` Suffix

`@` and a route key at the end of a name route it, and come off the name:

| On disk | In the game |
|---|---|
| `src/Trade/TradeService@Server.luau` | `ServerScriptService/Trade/TradeService` |
| `src/Trade/Admin@Server/Ban.luau` | `ServerScriptService/Trade/Admin/Ban` |

The file keeps its class, so `TradeService@Server.luau` is still a ModuleScript.

## Marker Files

An empty file named `@Server` routes the folder it's in, and the folder keeps its name:

| On disk | In the game |
|---|---|
| `src/Anticheat/@Server` | nothing |
| `src/Anticheat/Check.luau` | `ServerScriptService/Anticheat/Check` |

## Rojo's Script Suffixes

When your config has a `Server` or `Client` key, Rojo's `.server` and `.client` suffixes route a script as well as set its class:

| On disk | In the game |
|---|---|
| `src/Boot/Boot.server.luau` | `ServerScriptService/Boot/Boot`, a Script |
| `src/Boot/Hud.client.luau` | `StarterPlayer/StarterPlayerScripts/Boot/Hud`, a LocalScript |

A file that isn't a script routes with `@`, as in `Types@Shared.luau`.
