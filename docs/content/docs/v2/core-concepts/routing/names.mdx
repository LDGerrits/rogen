---
title: Routing by Name
description: Route a file or folder without moving it into a routing folder
---

When a feature is too small for routing folders, route by name instead.

## The `@` Suffix

`@` and a route key at the end of a name route it, and come off the name:

<RouteFigure
	disk={`
  src/
    Trade/
      Admin@Server/
        Ban.luau
      TradeService@Server.luau
      TradeTypes@Shared.luau
      TradeUi@Client.luau
`}
	studio={`
  ReplicatedStorage
    Shared/
      Trade/
        TradeTypes
  ServerScriptService
    Trade/
      Admin/
        Ban
      TradeService
  StarterPlayer
    StarterPlayerScripts
      Trade/
        TradeUi
`}
/>

A file keeps its class, so `TradeService@Server.luau` is still a ModuleScript.

## Marker Files

An empty file named `@Server` routes the folder it's in, and the folder keeps its name:

<RouteFigure
	disk={`
  src/
    Anticheat/
      @Server
      Check.luau
      Report.luau
`}
	studio={`
  ServerScriptService
    Anticheat/
      Check
      Report
`}
/>

## Init Scripts

An init script is its folder's instance, as in Rojo. A route in its name places only the script, so each side can have its own, and the folder's other files route by their own names:

<RouteFigure
	disk={`
  src/
    Shop/
      init@Server.luau
      init@Client.luau
      ShopService@Server.luau
      ShopUi@Client.luau
`}
	studio={`
  ServerScriptService
    Shop
      ShopService
  StarterPlayer
    StarterPlayerScripts
      Shop
        ShopUi
`}
/>

To send a whole folder with its init script, route the folder: name it `Shop@Server/`, or put a `@Server` marker file in it. A plain `init.luau` becomes the folder on every side that has no init script of its own.

Rojo reads only one file named `init.luau`, `init.server.luau` or `init.client.luau` per folder, so when two sides each have an init script, write the route with `@`. A Script keeps its suffix after the route, as in `init@Server.server.luau`.

## Rojo's Script Suffixes

When your config has a `Server` or `Client` key, Rojo's `.server` and `.client` suffixes route a script as well as set its class, so `Boot.server.luau` goes to the server. A sync rule's `suffix` routes another language's scripts the same way, such as `.server.lang`.
