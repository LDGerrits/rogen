---
title: Routing by Name
description: Route a file or folder without moving it into a routing folder
---

When a feature is too small for routing folders, route by name instead.

## The `@` Suffix

`@` and a route key at the end of a name route it, and come off the name:

<RouteFigure
	disk={`
  src/
    Trade/
      Admin@Server/
        Ban.luau
      TradeService@Server.luau
      TradeTypes@Shared.luau
      TradeUi@Client.luau
`}
	studio={`
  ReplicatedStorage
    Shared/
      Trade/
        TradeTypes
  ServerScriptService
    Trade/
      Admin/
        Ban
      TradeService
  StarterPlayer
    StarterPlayerScripts
      Trade/
        TradeUi
`}
/>

A file keeps its class, so `TradeService@Server.luau` is still a ModuleScript.

## Marker Files

An empty file named `@Server` routes the folder it's in, and the folder keeps its name:

<RouteFigure
	disk={`
  src/
    Anticheat/
      @Server
      Check.luau
      Report.luau
`}
	studio={`
  ServerScriptService
    Anticheat/
      Check
      Report
`}
/>

## Rojo's Script Suffixes

When your config has a `Server` or `Client` key, Rojo's `.server` and `.client` suffixes route a script as well as set its class:

<RouteFigure
	disk={`
  src/
    Boot/
      Boot.server.luau
      Hud.client.luau
`}
	studio={`
  ServerScriptService
    Boot/
      Boot
  StarterPlayer
    StarterPlayerScripts
      Boot/
        Hud
`}
/>

A file that isn't a script routes with `@`, as in `Types@Shared.luau`.

The extension doesn't matter. A language with its own extension routes the same way when a sync rule's `suffix` spells the class that its `use` gives, such as `.server.lang` with `serverScript`.

With a `compiledPath`, a script rule on an extension other than `.lua` and `.luau` names a compiled language, so one rule for the extension is enough. Rogen mounts the `.luau` file the compiler writes, and Rojo reads the class from that name. Only the rule's `pattern` counts for those files, since its `use` and `suffix` say nothing about the `.luau` file. The pattern should name the extension, as `*.lang` does: a broader one such as `src/**/*` also takes the `.luau` file, so Rojo reads that file by the rule and not by its name. A tool that copies such files unchanged into the `compiledPath` is not supported.
