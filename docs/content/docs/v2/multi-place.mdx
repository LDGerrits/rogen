---
title: Multi-Place Games
description: Set up Rogen for a game with more than one place
---

Each place has a config of its own, and shared code is a plain folder that every place lists in its `sourcePaths`. Where a place and the shared folder have a file at the same path, the place's file wins.

## Start a Multi-Place Game

In an empty folder, `rogen init --places` writes a first place, `lobby`, with its code in `src/lobby` and shared code in `src/common`:

```json title="lobby.rogen.json"
{
	"name": "lobby",
	"sourcePaths": ["src/common", "src/lobby"],
	"routes": {
		"server": "ServerScriptService",
		"client": "StarterPlayer/StarterPlayerScripts",
		"shared": "ReplicatedStorage/shared",
		"*": "ReplicatedStorage/shared"
	},
	"tree": { "$className": "DataModel" }
}
```

There is no `default.rogen.json`, so name the place in each command. To serve two places at once, give the second its own `--port`:

```bash
rogen serve lobby
rogen build lobby -o lobby.rbxl
```

## Add a Place

Copy the first config, then set its `"name"` to `"match"` and point `sourcePaths` at `src/match`. The copy carries the sample map in its tree:

```bash
cp lobby.rogen.json match.rogen.json
mkdir src/match
```

## Editor

With Luau, `rogen init --places` also writes `.vscode/settings.json`, which pins luau-lsp to the first place. luau-lsp reads one place at a time, `lobby` here. To switch, change the name in the `generatorCommand` in `.vscode/settings.json`.

## Places in roblox-ts

With `--language roblox-ts`, each place also gets a tsconfig that compiles the shared code and the place's own code into the place's `compiledPath`:

```json title="tsconfig.lobby.json"
{
	"extends": "./tsconfig.json",
	"compilerOptions": {
		"rootDir": "src",
		"rootDirs": ["src/common", "src/lobby"],
		"outDir": "out/lobby",
		"composite": true
	},
	"include": ["src/common", "src/lobby"],
	"rbxts": { "rojo": "lobby.project.json" }
}
```

Keep `rootDir` at `src`, the folder that holds both source paths, so the compiled files keep the folders they have in `src`; TypeScript 6 and later also refuse to compile without it. The root `tsconfig.json` holds the options every place shares and lists each place under `references`, so the editor checks a file against its own place.

To add a place, after copying the config as above:

1. Set `"compiledPath"` in `match.rogen.json` to `out/match`.
2. Copy `tsconfig.lobby.json` to `tsconfig.match.json` and change each `lobby` in it to `match`.
3. Add `{ "path": "./tsconfig.match.json" }` to the `references` in `tsconfig.json`.
4. Add ` && rbxtsc -p tsconfig.match.json` to the `build` script in `package.json`. `rbxtsc -w` runs until you stop it, so watch the new place from a terminal of its own with `npx rbxtsc -w -p tsconfig.match.json`.
