Rogen is a superset of Rojo that generates Rojo project files from your file system. You organize your game by feature, and Rogen puts each file in the right place.

## The Config

A Rogen config is a Rojo project file with `routes` added. The `tree` is the base: put in it what your folder names can't say, such as your packages, and Rogen adds every routed file to it.

```json title="default.rogen.json"
{
	"name": "my-game",
	"routes": {
		"Server": "ServerScriptService",
		"Client": "StarterPlayer/StarterPlayerScripts",
		"Shared": "ReplicatedStorage/Shared"
	},
	"tree": {
		"$className": "DataModel",
		"ReplicatedStorage": {
			"Packages": { "$path": "Packages" }
		}
	}
}
```

A folder named after a route sends its files there, so `src/Inventory/Server/InventoryService.luau` lands in `ServerScriptService/Inventory`. Rogen writes `default.project.json` from the config, and Rojo serves, builds and syncs your game as before. `rogen serve` and `rogen build` take Rojo's flags, and a project without a config works as it did.
