---
title: Using Syncback
description: Bring changes made in Studio back into your source files
---

`rogen syncback` writes the changes in a place file saved from Studio back into your source files. It needs Rojo 7.7.0 or newer.

In Studio, save the place with **File > Save to File As** as `game.rbxlx`, then preview:

```bash
rogen syncback --input game.rbxlx --dry-run
```

```
Writing src/Greeter/Shared/Greeting.luau
Writing src/Quest/Shared/QuestTypes.luau
Writing src/Greeter/Server/Welcome.luau
Writing src/Quest/Server/Main.server.luau
Removing src/Greeter/Client
Syncback would change 5 files (4 to write, 1 to remove).
```

Read the list before you write. Syncback also removes the files of instances the place no longer holds, so a place saved from an old copy undoes newer edits. When it looks right, run it again without `--dry-run`, adding `-y` in CI.

## Where Changes Go

A changed instance goes back to its own file, and a new one goes where routing would put it, styled like the files around it. Under a [`compiledPath`](/docs/v2/config), syncback leaves the compiled code alone and warns about each change for you to copy into the source.
