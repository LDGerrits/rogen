# Introduction

**Rogen** is a command line tool that brings feature-based architecture to Roblox development.

Instead of splitting your code into separate client, shared, and server folders at the root level, you group your code by domain. Rogen watches your files and dynamically generates your `default.project.json` map for Rojo. It sorts your code into the correct Roblox services automatically.

## Type-Based vs. Feature-Based

Traditional Roblox projects use a **type-based** structure. You split your code based on the environment where the code runs. If you build an `Inventory` feature, you place files in three different root folders. This forces you to switch context constantly to work on one feature.

Rogen introduces a **feature-based** structure. You keep all code for a feature inside one folder. This removes the need to navigate up and down your file tree.

Rogen reads your folder structure, marker files, and file names. It then maps your organized source code into the exact structure Roblox Studio expects.
