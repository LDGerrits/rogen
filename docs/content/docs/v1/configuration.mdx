`.rogen.json` configures your project: the source folders, how routing behaves, and the base project tree. Keep it in the project root.

Here's a fuller example with some top-level options and a mode that overrides them:

```json title=".rogen.json"
{
	"source": ["src"],
	"casing": "camelCase",
	"verbatim": false,
	"unwrap": false,
	"globIgnorePaths": ["**/_drafts/**"],
	"tags": {
		"dev": false,
		"prod": true
	},
	"aliases": {
		"Controller": "StarterPlayerScripts",
		"Service": "ServerScriptService"
	},
	"luau": {
		"output": "default.project.json",
		"build": "src",
		"tags": {
			"dev": true,
			"prod": false
		},
		"globIgnorePaths": ["**/*.spec.luau"]
	},
	"project": {
		"name": "my-game",
		"tree": {
			"$className": "DataModel"
		}
	}
}
```

---

## Fields

### `source`

_(Required)_ A string or an array of strings. The folders with your uncompiled code, which Rogen scans to build the tree. With an array, the folders are merged.

### `tags`

_(Optional)_ An object mapping tag names to booleans. `true` keeps the tagged files, and `false` drops them.

### `casing`

_(Optional)_ How the generated wrapper folders (like `server` or `client`) are capitalized: `"camelCase"` (the default) or `"PascalCase"`.

### `verbatim`

_(Optional)_ A boolean. Set it to `true` to keep routing keywords in script names instead of stripping them. Defaults to `false`.

### `unwrap`

_(Optional)_ A boolean. Set it to `true` to leave out the wrapper folders (`server`, `client` and `shared`) at the root of each service in Studio.

### `aliases`

_(Optional)_ An object of custom routing keywords. Use it to add your own keywords or change where the built-in ones go.

### `globIgnorePaths`

_(Optional)_ An array of glob patterns. Matching files and folders are ignored completely.

### `project`

_(Optional)_ The base Rojo tree, either inline or as a path to a JSON file. Rogen merges the paths it generates into it.

---

## Modes

A mode is a pipeline for one workflow, such as `luau`, `ts` or `darklua`. You can define your own modes too.

### `output`

_(Required)_ The path of the Rojo project file to write.

### `build`

_(Required)_ The folder whose code gets synced to Studio.

### `tags`

_(Optional)_ An object mapping tag names to booleans, overriding the top-level `tags` for this mode.

### `globIgnorePaths`

_(Optional)_ An array of glob patterns to ignore in this mode.

```json title=".rogen.json"
{
	"dev": {
		"output": "dev.project.json",
		"build": "src",
		"tags": {
			"dev": true,
			"prod": false
		},
		"globIgnorePaths": ["**/*.spec.luau"]
	}
}
```
