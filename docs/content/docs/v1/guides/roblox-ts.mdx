# Roblox-TS Setup

Rogen integrates smoothly with [roblox-ts](https://roblox-ts.com/). It automatically detects your `tsconfig.json` file and adjusts its build targets.

While roblox-ts compiles `.ts` files into an `out` folder, Rogen still reads your uncompiled `src` folder to build the map. It swaps the file extensions to `.luau` and points Rojo to your compile output.

<Steps>

<Step>
### Configure Rogen

Initialize your config file using the CLI:

```bash
rogen --init
```

Because Rogen detects roblox-ts, it configures a `ts` mode automatically. Ensure the `build` path matches the `outDir` in your `tsconfig.json`.

```json title=".rogen.json"
{
	"source": ["src"],
	"ts": {
		"output": "default.project.json",
		"build": "out"
	},
	"template": {
		"name": "my-ts-game",
		"globIgnorePaths": ["**/package.json", "**/tsconfig.json"],
		"tree": {
			"$className": "DataModel"
		}
	}
}
```

</Step>

<Step>
### Run the Pipeline

You need to run the `rbxtsc` compiler and Rogen at the same time. We recommend installing `concurrently`:

```bash
npm install -D concurrently
```

Update your `package.json` script to run both watchers:

```json
"scripts": {
	"watch": "concurrently \"rogen -w\" \"rbxtsc -w\""
}
```

Then run the script:

```bash
npm run watch
```

</Step>

</Steps>
