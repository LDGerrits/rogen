# Luau Setup

Using Rogen with standard Luau is simple. Since Luau needs no compilation step, Rogen reads your source directory and generates a map for Rojo automatically.

<Steps>

<Step>
### Initialize your Project

First, create a basic file structure. Place all your source code inside a `src/` directory.

```bash
mkdir src
```

</Step>

<Step>
### Create the Rogen Config

Use Rogen to generate a default `.rogen.json` file. Run this command in your project root:

```bash
rogen --init
```

This creates a configuration file that tells Rogen to scan the `src` folder and output a `default.project.json` file for the `luau` mode.

</Step>

<Step>
### Start the Watcher

Run Rogen in watch mode. It builds the project file and updates it automatically when you change files.

```bash
rogen -w
```

</Step>

<Step>
### Sync with Rojo

In a separate terminal window, start Rojo using the file Rogen generated.

```bash
rojo serve
```

</Step>

</Steps>

You can now create feature-based folders (e.g., `src/combat/client`) and Rogen will route them correctly.
