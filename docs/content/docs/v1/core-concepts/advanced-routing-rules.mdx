import { Callout } from "fumadocs-ui/components/callout";

<Callout type="warning" title="Init files">
	A folder with an init file (`init.luau`, `index.ts`) is routed as usual,
	but Rogen doesn't apply any routing rules to what's inside it.
</Callout>

<Callout type="warning" title="Data and asset files">
	Rogen can't write direct paths for files like `.json` or `.toml`. It tells
	you in the console when one of them needs to be wrapped in a folder.
</Callout>

<Steps>

<Step>
### Invisible Folders

Group files on disk without changing where they end up in Studio. Wrap a folder name in parentheses, like `(inventory)`, and Rogen leaves the folder out but keeps its contents.

</Step>

<Step>
### File Hoisting

To put a script at the root of its service, start its name with `^`:

- File: `src/core/physics/server/^collision-service.ts`
- Result: placed directly in `ServerScriptService`.

</Step>

<Step>
### Advanced Marker Files

An empty file in a folder changes how Rogen treats that folder and everything below it.

- **`.structure`** keeps the folder layout exactly as it is by turning routing off. Tag filtering still applies.
- **`.sync`** stops Rogen from looking inside and syncs the folder as it is, with no routing or tag filtering.
- **`.verbatim`** keeps routing keywords in file names, so `InputClient` keeps its `Client`.
- **`.unwrap`** keeps the wrapper folders (`server`, `client` and `shared`) out of Studio.

</Step>

</Steps>
