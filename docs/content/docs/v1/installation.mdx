Install Rogen using **Rokit**.

<Callout type="info">
	**Prerequisite:** Install [Rojo](https://github.com/rojo-rbx/rojo) or
	[Argon](https://github.com/argon-rbx/argon) to sync code to Roblox Studio.
</Callout>

<Steps>

<Step>
### Add Rogen to the toolchain

Open `rokit.toml` file and add Rogen.

<InstallCodeBlock />

</Step>

<Step>
### Install the Tool

Run the installation command.

```bash
rokit install
```

</Step>

<Step>
### Verify Installation

Check the Rogen version.

```bash
rogen version
```

If the command prints a version number, the install was succesful.

</Step>

</Steps>
