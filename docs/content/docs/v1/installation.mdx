You can install Rogen with **Rokit** or **npm**.

<Callout type="info">
	Rogen writes the project file, but [Rojo](https://github.com/rojo-rbx/rojo)
	or [Argon](https://github.com/argon-rbx/argon) does the syncing, so you'll
	need one of them too.
</Callout>

<Tabs items={["Rokit", "npm"]}>
  <Tab value="Rokit">
    <Steps>
      <Step>
        ### Add Rogen to Rokit

        Add Rogen to your `rokit.toml`:

        <InstallCodeBlock />

      </Step>

      <Step>
        ### Install

        ```bash
        rokit install
        ```

      </Step>

      <Step>
        ### Check It Works

        ```bash
        rogen version
        ```

        If this prints a version number, you're set.

      </Step>
    </Steps>

  </Tab>

  <Tab value="npm">
    <Steps>
      <Step>
        ### Install

        Add Rogen to your project:

        ```bash
        npm i @ldgerrits/rogen
        ```

      </Step>

      <Step>
        ### Check It Works

        Run the local install through `npx`:

        ```bash
        npx rogen version
        ```

        If this prints a version number, you're set.

      </Step>
    </Steps>

  </Tab>
</Tabs>
