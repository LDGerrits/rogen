# Installation

Rogen is a command line tool. Install it using **Rokit**.

<Callout type="info">
	**Prerequisite:** You must install
	<a
		href="[https://rojo.space/](https://rojo.space/)"
		target="_blank"
		rel="noreferrer"
	>
		Rojo
	</a>
	. Rogen generates Rojo
	<code>.project.json</code> files.
</Callout>

<Steps>

<Step>
### Add Rogen to your Toolchain

Open your `rokit.toml` file and add Rogen.

<InstallCodeBlock />

</Step>

<Step>
### Install the Tool

Run the installation command.

```bash
rokit install
```

</Step>

<Step>
### Verify Installation

Check the Rogen version.

```bash
rogen --version
```

If the command prints a version number, you are ready.

</Step>

</Steps>
