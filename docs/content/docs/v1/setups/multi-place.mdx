---
title: Multi-Place
description: Share code across several places in one repo.
---

import { Steps, Step } from "fumadocs-ui/components/steps";
import { Callout } from "fumadocs-ui/components/callout";

Give each place its own config that combines the shared code with the place's own folder.

<Steps>

<Step>
### Structure the Repository

Keep shared code and each place's code in separate folders:

<SystemWindow>
	<TreeFolder name="src" open />
	<TreeFolder level={1} name="core" />
	<TreeFolder level={1} name="lobby" />
	<TreeFolder level={1} name="match" />
</SystemWindow>

</Step>

<Step>
### Configure the Lobby Place

Create a config for the lobby, and list both folders in `source`:

```json title="lobby.rogen.json"
{
	"source": ["core", "lobby"],
	"luau": {
		"output": "lobby.project.json",
		"build": "src"
	},
	"project": {
		"name": "lobby",
		"tree": {
			"$className": "DataModel"
		}
	}
}
```

Rogen reads every listed folder and merges them into one tree.

</Step>

<Step>
### Configure the Match Place

Do the same for the match:

```json title="match.rogen.json"
{
	"source": ["core", "match"],
	"luau": {
		"output": "match.project.json",
		"build": "src"
	},
	"project": {
		"name": "match",
		"tree": {
			"$className": "DataModel"
		}
	}
}
```

</Step>

<Step>
### Start Watching

Pick the config to build with `-c` or `--config`:

```bash
rogen watch --config lobby.rogen.json
```

</Step>

</Steps>

<Callout type="info">
	If two folders have a file at the same path, the one listed last in
	`source` wins.
</Callout>
