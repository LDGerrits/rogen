[Darklua](https://github.com/seaofvoices/darklua) applies rules to your code and writes the result to a build folder. Rogen detects it when there's a `.darklua.json` or `.darklua.json5` in the project root.

<Steps>

<Step>
### Define the Build Directory

This guide assumes Darklua reads from `src` and writes to `dist`.

</Step>

<Step>
### Configure Rogen

In the project root, run:

```bash
rogen init
```

Rogen detects Darklua and adds a `darklua` mode to `.rogen.json`. Make sure `build` matches Darklua's output folder.

```json title=".rogen.json"
{
	"source": ["src"],
	"darklua": {
		"output": "build.project.json",
		"build": "dist"
	},
	"project": {
		"name": "my-darklua-game",
		"tree": {
			"$className": "DataModel"
		}
	}
}
```

Rogen reads `src` to work out the routing, but points the paths in the project file at `dist`.

</Step>

<Step>
### Run the Pipeline

Run Darklua in watch mode to process `src` into `dist`, and Rogen in watch mode next to it:

```bash
darklua process src dist --watch
```

```bash
rogen watch
```

</Step>

</Steps>
