With [roblox-ts](https://roblox-ts.com/), Rogen reads your uncompiled `src` folder to work out the routing, then points Rojo at the compiled output, with the extensions swapped to `.luau`.

<Steps>

<Step>
### Configure Rogen

In the project root, run:

```bash
rogen init
```

Rogen detects roblox-ts and sets up a `ts` mode. Check that `build` matches the `outDir` in your `tsconfig.json`.

```json title=".rogen.json"
{
	"source": ["src"],
	"ts": {
		"output": "default.project.json",
		"build": "out"
	},
	"project": {
		"name": "my-ts-game",
		"globIgnorePaths": ["**/package.json", "**/tsconfig.json"],
		"tree": {
			"$className": "DataModel"
		}
	}
}
```

</Step>

<Step>
### Run the Pipeline

`rbxtsc` and Rogen need to run side by side. One easy way to do that is with `concurrently`:

```bash
npm install -D concurrently
```

Add a script to `package.json` that starts both watchers:

```json
"scripts": {
	"watch": "concurrently \"rogen watch\" \"rbxtsc -w\""
}
```

Then run it:

```bash
npm run watch
```

</Step>

</Steps>
