import { Steps, Step } from "fumadocs-ui/components/steps";

Luau is the simplest setup: Rogen reads your source folder and writes the project file, with no compiler in between.

<Steps>

<Step>
### Create the Config

In the project root, run:

```bash
rogen init
```

This creates a `.rogen.json` with a `luau` mode that scans `src` and writes `default.project.json`.

</Step>

<Step>
### Start Watching

Start Rogen in watch mode. It builds the project file and keeps it up to date as you work.

```bash
rogen watch
```

</Step>

<Step>
### Sync with Rojo

In a second terminal, start Rojo:

```bash
rojo serve
```

</Step>

</Steps>
