A CLI tool enabling feature-based architecture through automated routing of client, server, and shared code to Roblox services.

## Features

- **Feature Folders:** Store related client, server and shared scripts inside a single folder.
- **Auto-Routing:** Route files to Roblox services automatically using Rojo or Argon.
- **Multi-Place Support:** Merge multiple source directories to share core systems across different places.
- **Environment Tags:** Filter test files and inject mock files at build time using tags.
- **Custom Pathing:** Control the final output structure using invisible folders and marker files.
- **Modern Tooling:** Support Luau, roblox-ts, and Darklua pipelines out of the box.
