---

**Rogen** lets you structure your Roblox games using feature-based folders. Instead of splitting your code across separate client, server, and shared roots, you keep all files for a specific feature in one place.

## Features

- **Feature-Based Routing:** Group your client, server, and shared code side by side.
- **Multi-Place Merging:** Combine multiple source folders into a single Rojo project to share core code easily.
- **Environment Filtering:** Exclude test files and development tools from production builds using simple tags.
- **Advanced Pathing:** Control your exact output structure using invisible folders, file hoisting, and marker files.
- **Broad Support:** Works seamlessly with Luau, roblox-ts, and Darklua.
