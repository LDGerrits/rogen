## What's here
`{{source}}` holds the code every place shares, here the `Greeter` feature: one folder for the code that belongs together. `src/{{place}}` holds the code of the {{place}} place alone.

A place is a `<place>.rogen.json` at the root: `{{place}}.rogen.json` lists the source paths `{{source}}` and `src/{{place}}`, and Rogen writes `{{place}}.project.json` from it. `tsconfig.{{place}}.json` compiles the same two folders into `out/{{place}}`, with `src` as its `rootDir`, and `tsconfig.json` holds the options every place shares.

The tree in `{{place}}.rogen.json` holds Rojo's sample Baseplate and the Lighting and SoundService settings, as `$properties` and a `Baseplate` node, and Rogen routes nothing in it.

The folders inside a feature decide where its code runs: `server` goes to ServerScriptService, `client` to StarterPlayerScripts and `shared` to ReplicatedStorage/shared. To see where a file lands, and how to require it, use:

```bash
rogen where {{source}}/Greeter/shared/Greeting.ts
```

## Getting Started
To compile the TypeScript, and keep compiling it as you edit, use this in a terminal of its own:

```bash
npm run watch
```

To serve the {{place}} place and connect to it from Roblox Studio, use:

```bash
{{serve}}
```

To build the {{place}} place from scratch, use:

```bash
rogen build {{place}} -o "{{name}}.rbxlx"
```

## Changing the project
Edit `{{place}}.rogen.json`, not `{{place}}.project.json`, which `rogen write` replaces. After you add a feature folder, run `rogen write {{place}}` so the editor's `{{place}}.project.json` follows. The `routes` in each config say where each folder's code goes, and a folder to place as it is, such as `Packages`, is mounted in the `tree` of each.

## Adding a place
Copy `{{place}}.rogen.json` to `match.rogen.json` and `tsconfig.{{place}}.json` to `tsconfig.match.json`, change each `{{place}}` in both copies to `match`, and make the `src/match` folder. Add `{ "path": "./tsconfig.match.json" }` to the `references` in `tsconfig.json`, and ` && rbxtsc -p tsconfig.match.json` to the end of the `build` script in `package.json`. `rbxtsc -w` runs until you stop it, so watch the new place from a terminal of its own:

```bash
npx rbxtsc -w -p tsconfig.match.json
```

A second place is served from a second terminal, with its own `--port`:

```bash
rogen serve match --port <port>
```
