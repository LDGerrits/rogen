## What's here
`{{source}}` holds the code every place shares, here the `Greeter` feature: one folder for the code that belongs together. `{{place}}` holds the code of the game place alone.

The folders inside a feature decide where its code runs: `server` goes to ServerScriptService, `client` to StarterPlayerScripts and `shared` to ReplicatedStorage. To see where a file lands, and how to require it, use:

```bash
rogen where {{source}}/Greeter/shared/Greeting.ts
```

## Getting Started
To compile the TypeScript, and keep compiling it as you edit, use this in a terminal of its own:

```bash
npm run watch
```

To serve the game place and connect to it from Roblox Studio, use:

```bash
{{serve}}
```

To build the game place from scratch, use:

```bash
rogen build {{place}} -o "{{name}}.rbxlx"
```

To add a place, use:

```bash
rogen init projects/lobby
```

A second place is served from a second terminal, with its own `--port`:

```bash
rogen serve projects/lobby --port <port>
```

For more help, check out [the Rogen documentation](https://rogen-playfully.vercel.app/).
