## What's here
`{{source}}` holds the code every place shares, here the `Greeter` feature: one folder for the code that belongs together. A place is a folder under `projects`: `projects/{{place}}/src` holds the code of the {{place}} place alone, and `projects/{{place}}/default.rogen.json` lists the source paths `../common/src` and `src`. Rogen writes `projects/{{place}}/default.project.json` from it, and `projects/{{place}}/compiler.project.json`, the same file without the folders the compiler would reject inside its `rootDir`.

`projects/{{place}}/tsconfig.json` is the place's own compiler config: it compiles `src` and `../common/src` into `out/{{place}}`, with `projects` as its `rootDir`. `tsconfig.{{place}}.json` at the root extends it, and the `build` and `watch` scripts compile through it. `tsconfig.json` holds the options every place shares.

The tree in `projects/{{place}}/default.rogen.json` holds Rojo's sample Baseplate and the Lighting and SoundService settings, as `$properties` and a `Baseplate` node, and Rogen routes nothing in it.

The folders inside a feature decide where its code runs: `server` goes to ServerScriptService, `client` to StarterPlayerScripts and `shared` to ReplicatedStorage/shared. To see where a file lands, and how to require it, use:

```bash
rogen where {{source}}/Greeter/shared/Greeting.ts
```

`rogen check` and `rogen where` find the place a path belongs to, and a file in `projects/common` belongs to every place. `rogen where {{target}}` lists the files of one place.

## Getting Started
To compile the TypeScript, and keep compiling it as you edit, use this in a terminal of its own:

```bash
npm run watch
```

To serve the {{place}} place and connect to it from Roblox Studio, use:

```bash
{{serve}}
```

To build the {{place}} place from scratch, use:

```bash
rogen build {{target}} -o "{{name}}.rbxlx"
```

## Adding a place
Copy `projects/{{place}}` to `projects/lobby` and set `name` in `projects/lobby/default.rogen.json` to `lobby`. In the copy, change `{{place}}` to `lobby` in the `outDir` and `tsBuildInfoFile` of `projects/lobby/tsconfig.json` and in the `compiledPath` of `default.rogen.json`. Copy `tsconfig.{{place}}.json` to `tsconfig.lobby.json`, change `{{place}}` in it to `lobby`, add `{ "path": "./projects/lobby" }` to the `references` in `tsconfig.json`, and add ` && rbxtsc -p tsconfig.lobby.json` to the end of the `build` script in `package.json`. `rbxtsc -w` runs until you stop it, so watch the new place from a terminal of its own:

```bash
npx rbxtsc -w -p tsconfig.lobby.json
```

A second place is served from a second terminal, with its own `--port`:

```bash
rogen serve projects/lobby --port <port>
```
