## What's here
`{{source}}` holds the code every place shares, here the `greeter` feature: one folder for the code that belongs together. `src/{{place}}` holds the code of the {{place}} place alone.

A place is a `<place>.rogen.json` at the root: `{{place}}.rogen.json` lists the source paths `{{source}}` and `src/{{place}}`, and Rogen writes `{{place}}.project.json` from it.

The tree in `{{place}}.rogen.json` holds Rojo's sample Baseplate and the Lighting and SoundService settings, as `$properties` and a `Baseplate` node, and Rogen routes nothing in it.

The folders inside a feature decide where its code runs: `server` goes to ServerScriptService, `client` to StarterPlayerScripts and `shared` to ReplicatedStorage/Shared. To see where a file lands, and how to require it, use:

```bash
rogen where {{source}}/greeter/shared/Greeting.luau
```

`rogen check` and `rogen where` find the place a path belongs to, and a file in `src/common` belongs to every place. `rogen check` with no path checks every place. `rogen where {{place}}` lists the files of one place.

## Getting Started
To serve the {{place}} place and connect to it from Roblox Studio, use:

```bash
{{serve}}
```

To build the {{place}} place from scratch, use:

```bash
rogen build {{place}} -o "{{name}}.rbxlx"
```

## Changing the project
Edit `{{place}}.rogen.json`, not `{{place}}.project.json`, which `rogen write` replaces. After you add a feature folder, run `rogen write {{place}}` so the editor's `{{place}}.project.json` follows. The `routes` in each config say where each folder's code goes, and a folder to place as it is, such as `Packages`, is mounted in the `tree` of each.

## Adding a place
Copy `{{place}}.rogen.json` to `match.rogen.json`, change its `name` to `match` and its source path `src/{{place}}` to `src/match`, and make the `src/match` folder. A second place is served from a second terminal, with its own `--port`:

```bash
rogen serve match --port <port>
```

## Editor
A sourcemap describes one place, so luau-lsp knows one place at a time: the one in `.vscode/settings.json`. It runs

```bash
rogen sourcemap {{place}} --watch -o sourcemap.json
```

to keep `sourcemap.json` current as files come and go. To switch place, change `{{place}}` to the name of another in that setting.

To check every place exactly at once, for an agent or CI, check each place against its own sourcemap:

```bash
rogen sourcemap {{place}} -o sourcemap.json && luau-lsp analyze --definitions=@roblox=<types.d.luau> --sourcemap=sourcemap.json {{source}} src/{{place}}
```
