## What's here
`{{source}}` holds the code every place shares, here the `Greeter` feature: one folder for the code that belongs together. `src/{{place}}` holds the code of the {{place}} place alone.

A place is a `<place>.rogen.json` at the root: `{{place}}.rogen.json` lists the source paths `{{source}}` and `src/{{place}}`, and Rogen writes `{{place}}.project.json` from it.

`place/{{place}}` holds Rojo's sample Baseplate and the Lighting and SoundService settings, as Rojo files: an `init.meta.json` per service and `Workspace/Baseplate.model.json`. The tree in `{{place}}.rogen.json` mounts each service's folder, and Rogen routes nothing in it.

The folders inside a feature decide where its code runs: `Server` goes to ServerScriptService, `Client` to StarterPlayerScripts and `Shared` to ReplicatedStorage. To see where a file lands, and how to require it, use:

```bash
rogen where {{source}}/Greeter/Shared/Greeting.luau
```

`rogen check` and `rogen where` find the place a path belongs to, and a file in `src/common` belongs to every place. `rogen check` with no path checks every place. `rogen where` finds no `default.rogen.json` here, so name the place: `rogen where {{place}}.rogen.json`.

## Getting Started
To serve the {{place}} place and connect to it from Roblox Studio, use:

```bash
{{serve}}
```

To build the {{place}} place from scratch, use:

```bash
rogen build {{place}} -o "{{name}}.rbxlx"
```

## Adding a place
Copy `{{place}}.rogen.json` to `lobby.rogen.json`, change its `name` to `lobby` and its source path `src/{{place}}` to `src/lobby`, and make the `src/lobby` folder. A second place is served from a second terminal, with its own `--port`:

```bash
rogen serve lobby --port <port>
```

## Editor
A sourcemap describes one place, so luau-lsp knows one place at a time: the one in `.vscode/settings.json`. It runs

```bash
rogen sourcemap {{place}} --watch -o sourcemap.json
```

to keep `sourcemap.json` current as files come and go. To switch place, change `{{place}}` to the name of another in that setting.

To check every place exactly at once, for an agent or CI, check each place against its own sourcemap:

```bash
rogen sourcemap {{place}} -o sourcemap.json && luau-lsp analyze --definitions=@roblox=<types.d.luau> --sourcemap=sourcemap.json {{source}} src/{{place}}
```
