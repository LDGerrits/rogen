## What's here
`{{source}}` holds the code every place shares, here the `Greeter` feature: one folder for the code that belongs together. A place is a folder under `projects`: `projects/{{place}}/src` holds the code of the {{place}} place alone, and `projects/{{place}}/default.rogen.json` lists the source paths `../common/src` and `src`. Rogen writes `projects/{{place}}/default.project.json` from it.

The tree in `projects/{{place}}/default.rogen.json` holds Rojo's sample Baseplate and the Lighting and SoundService settings, as `$properties` and a `Baseplate` node, and Rogen routes nothing in it.

The folders inside a feature decide where its code runs: `Server` goes to ServerScriptService, `Client` to StarterPlayerScripts and `Shared` to ReplicatedStorage/Shared. To see where a file lands, and how to require it, use:

```bash
rogen where {{source}}/Greeter/Shared/Greeting.luau
```

`rogen check` and `rogen where` find the place a path belongs to, and a file in `projects/common` belongs to every place. `rogen where {{target}}` lists the files of one place.

## Getting Started
To serve the {{place}} place and connect to it from Roblox Studio, use:

```bash
{{serve}}
```

To build the {{place}} place from scratch, use:

```bash
rogen build {{target}} -o "{{name}}.rbxlx"
```

## Adding a place
Copy `projects/{{place}}` to `projects/lobby`, set `name` in `projects/lobby/default.rogen.json` to `lobby`, and add `{ "path": "projects/lobby" }` to the folders in `{{name}}.code-workspace`. A second place is served from a second terminal, with its own `--port`:

```bash
rogen serve projects/lobby --port <port>
```

## Editor
Open `{{name}}.code-workspace` in VS Code, not the folder. luau-lsp reads one sourcemap per workspace folder, so each place is typed against its own code. In the workspace file, each folder runs

```bash
rogen sourcemap --watch -o sourcemap.json
```

to keep its `sourcemap.json` current as files come and go. `projects/common` has no project file of its own, so `projects/common/.vscode/settings.json` makes it read the sourcemap of `projects/{{place}}`; the shared code is typed as part of that place.

StyLua finds the `stylua.toml` at the root from every folder. Selene reads only the `selene.toml` in the folder it runs in, so put one in `projects/common` and in each place's folder.

To check every place exactly at once, for an agent or CI, check each place from its own folder, against its own sourcemap:

```bash
cd {{target}} && rogen sourcemap -o sourcemap.json && luau-lsp analyze --definitions=@roblox=<types.d.luau> --sourcemap=sourcemap.json src ../common/src
```
