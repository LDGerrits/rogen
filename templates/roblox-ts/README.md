## Getting Started
To compile the TypeScript, and keep compiling it as you edit, use this in a terminal of its own:

```bash
npm run watch
```

To build the place from scratch, use:

```bash
rogen build -o "{{name}}.rbxlx"
```

Next, open `{{name}}.rbxlx` in Roblox Studio and start the Rojo server:

```bash
{{serve}}
```
